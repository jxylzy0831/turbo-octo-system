# 十二层评审与验证

用于整本逆向、具体问题诊断和返修。按任务范围选择层面，不能为了凑齐十二项虚构材料。

## 十二层检查

| 层面 | 核查问题 | 应落到的证据或成果 |
| --- | --- | --- |
| 故事架构 | 世界规则、主支线、时序与因果是否相容？ | 事件链及依赖关系 |
| 人物设计 | 欲望、恐惧、秘密和缺陷是否推动行动？ | 具体选择与代价 |
| 关系网络 | PC-PC、PC-NPC、NPC-NPC 的关系是否产生后果？ | 可行动关系边，纯背景边另记 |
| 情感结构 | 从什么关系状态开始，经哪些经历改变？ | 递进过程及断点 |
| 互动机制 | 谁为何发起，对方如何回应，何时结束？ | 双向动作、话题来源和备用入口 |
| 情绪调度 | 哪些前置积累支持当前情绪转变？ | 预期变化、触发与消化空间 |
| 伏笔与反转 | 新信息改变了哪个旧解释；知情者是否合理？ | 事实/解释对照及信息表 |
| 沉浸机制 | 物件、仪式、环境怎样进入玩家经历？ | 实际使用动作，故障替代 |
| NPC 表演 | 有无目标、潜台词、状态切换和临场回应？ | 知情范围及反应分支 |
| 流程控制 | 时间、场地、演员和玩家注意力是否冲突？ | 时段安排、等待活动、转场条件 |
| 玩家心理 | 声称的感受来自文本还是实际反馈？ | 可观察行为与未证实假设 |
| 创作方法 | 能否从具体安排抽象出有条件的规则？ | 使用条件、失效情况、反例与待测项 |

分析记录可用以下最小结构。

`来源位置｜原文安排｜文本明确证实的事实｜根据设计推断的功能｜可能的其他解释｜需要实测验证的效果｜可迁移条件`

来源缺页、版本歧义与原作矛盾分别列出。缺少材料不等于作品没有设计；未经证据支持也不能替作者补上设计。影响当前创作的核心冲突按项目要求记录并请用户裁定。

## 从症状到改动

| 症状 | 优先检查 | 可能的修改方向 |
| --- | --- | --- |
| 两人没话聊 | 是否有当下所求；回答是否影响下一步 | 加入需要双方协商的小事，或让未解释的行为产生具体后果 |
| NPC 只是发糖工具 | 行为是否回应人物特定需求；是否有自己的目标 | 让照顾与自身责任共存，用具体回应替换通用情话 |
| 群像各谈各的 | 公共事件是否改变私人关系；非 CP 是否有行动 | 增加跨关系的合作、请求或承担后果，减少无关旁观 |
| 反转正确却无感 | 玩家是否经历过被重释的事情 | 先补共同经历或改变揭示后的可参与行动，再考虑加重悲剧 |
| 流程经常冷场 | 触发是否可见；是否必须说出特定答案 | 缩小提问、增加可信替代入口、明确可收束条件 |
| 玩家选择被吞掉 | 选项承诺与实际结果是否一致 | 改成真实过程分支，或明确表达选择并承接立场 |

方向必须依当前文本验证后使用，不能看到症状就机械加任务、道具或秘密。

返修记录使用：`位置 → 断裂原因 → 本轮实际改动 → 涉及的前后文 → 核查结果`。先修承重关系和信息逻辑，再润色台词。若只要求评审，交付可执行建议；若要求修稿，落实成新版本。

## 反事实检查与实测

先做桌面推演，用“预计、可能”描述结果。可选择删除一个互动、移除一件道具、提前一个揭示或更换一名连接型 NPC，追踪哪些后文失去条件。删除无影响有多种解释：设计冗余、其他场景已承担功能、或者判断材料不足，不能直接断言该场景无用。

需要验证效果时设计一次改变一个关键因素的对照。

| 项目 | 记录内容 |
| --- | --- |
| 假设 | 具体安排可能促成什么，为什么 |
| A/B 版本 | 哪一个因素改变，哪些条件尽量保持一致 |
| 观察 | 主动发起、回应内容、角色间合作、记住的共同经历、等待情况 |
| 复盘 | 让玩家用自己的话说明哪段关系变了、哪次选择有作用，不诱导其承认感动 |
| 混杂因素 | 演员、玩家偏好、熟悉程度、顺序、音乐、时长差异 |
| 结论限制 | 样本与实际记录支持什么，尚不能说明什么 |

例如比较“玩家一起选出礼物”与“NPC 直接交付同样礼物”，观察是否改变共同经历的记忆和主动提及。此例只是测试设计，没有预设胜出版本。

哭泣、感动自评、对 NPC 角色的投入及对演员本人的好感分别看待。一次演出不能证明普遍因果，不编造精确成功率。文本校验、同一代理桌面推演、独立评审和现场实测应分别报告。

## 给 AI 的积累格式

用户要求建立案例库时，可将场景保存成 JSONL 或表格。每条保留材料版本、出处、角色与配置、关系起点、互动触发、行动、结果、证据等级、反例、测试状态和迁移条件。未经测试的条目明确标记“未实测”。

新作品另建记录，不把不同作品的设定与规则混在一起。多部作品支持同一候选方法时，也要记录条件差异与失败例。案例库可以支持检索、提示和评审，不能据此声称模型权重已经完成训练。
