# 结构与关系设计

用于整本策划、人物关系与情感递进。以下字段是工作工具，可合并成自然语言，不要求用户逐项填表。

## 从需求走到行动

为主要角色写一个短记录。

| 字段 | 要回答的问题 |
| --- | --- |
| 现实处境 | 目前有什么资源、责任和不能轻易离开的困境？ |
| 核心需求 | 最希望得到谁的哪种回应？ |
| 惯用办法 | 是争夺、试探、交换、照顾、逃避，还是其他具体行为？ |
| 恐惧与界限 | 害怕什么发生；什么事即使为了爱也不愿做？ |
| 秘密与矛盾 | 知道什么；想要的东西怎样相互冲突？ |
| 可经历的改变 | 哪次行动与后果可能改变其做法？也允许拒绝成长。 |

不要把抽象标签直接当人物差异。两个角色都怕被抛弃，一个可能先走，一个可能反复要求确认，行为后果才会生成不同的戏。

## 关系必须产生行动

用“甲需要乙做什么，乙为何愿意或不愿意，谁为此付出什么”描述关系。主要关系至少能指向一段现场行为或重要剧情后果；纯背景关系可以保留，但不要计作已经发生的玩家互动。

CP 内分别确定互相给予、无法轻易兼容的需求、共同经历及可以协商的范围。全桌则追踪 CP 之外的关系是否进入现场。不设机械的交叉边数量，按人数、时长和主题选择有后果的关系。

可用关系边记录：

`甲 → 乙｜关系历史｜当前所求｜乙的阻力｜触发事件｜玩家可采取的行动｜后果由谁承接`

群像检查尤其关注两种边。一种让玩家共同做事；另一种让甲的行动改变乙的处境。共同敌人可以促成合作，但不能自动消除所有责任与道德分歧。

## 情感积累的候选链条

`角色需求 → 接近理由 → 共同经历 → 对彼此形成预期 → 预期被回应或打破 → 玩家作出回应 → 后续关系改变`

这是一种设计检视顺序，可以循环、逆行或停留，不能当作真实心理的必然规律。对重逢关系，历史能提前提供期待；对初识关系，必须在当前经历中建立信任依据，不能直接搬用恋人待遇。

需要设计重复互动时，每次增加一点新内容。

| 次序 | 可承担的功能 | 失效征兆 |
| --- | --- | --- |
| 首次 | 让一个动作、称呼或约定发生 | 只有旁白说它重要，玩家没有理解或参与 |
| 再次 | 回应先前细节，形成可识别的相处方式 | 原样重复，关系没有新增内容 |
| 改变 | 环境、代价、选择或含义发生变化 | 只靠突然失踪或死亡制造刺激 |
| 回应 | 玩家决定如何理解或接续它 | 主持包办全部答案，只剩观看 |

物品只是载体。共同习惯、未完成的问题、两人的暗号、做事方式也能承担记忆；没有合适功能时无需发道具。

## 故事与信息分开编排

维护两个简表。

1. 事件因果表：真实发生顺序、行动者、动机、条件、事件、直接后果。
2. 信息表：事实、谁何时知道、通过何种证据知道、哪些人仍不知、何时允许公开。

倒叙改变展示顺序，不能修补事件本身没有原因的问题。角色不能仅因演员读过手册就知道私聊内容。主观回忆、幻象、转述和现实出场分别标识，尤其检查谁能看见、回应并留下公共证据。

安排反转时记录：

`前期可见事实｜角色/玩家可能作出的解释｜后来新增证据｜被改变的旧解释｜仍然成立的原行为动机｜玩家揭示后能做什么`

若反转只有新增惨事，无法指向可回看的前期经历，按新增剧情评估，不夸称其已完成情感回收。不能为了藏信息让聪明角色突然失去判断力。玩家提前猜中后，可以把悬念转向“人物为什么这样做、接下来如何选择”；不必否认合理推断来保住惊喜。

## 公共主线与逐幕推进

为各幕写公共变化及其私人后果，并逐人查看其参与机会。

`本幕公共事件｜每人当前目标｜可执行行动｜得到/失去的信息或资源｜关系变化｜下一幕入口`

情绪调度先写预期体验与触发条件，如“玩笑建立相处习惯后，再让未完成的约定进入讨论”。没有实测时不画精确强度分数。适时安排阅读、轻松相处和行动后的消化，连续揭露惨事不等于持续有效的情感积累。

只有用户要求全套创作时才展开完整多幕、角色本、主持手册。单段返修应追踪必要的前后依赖，保留其余已确认内容。
