# 互动与主持流程

用于双人互动、NPC 主动行为、群像调度，以及玩家本和主持手册配套编写。

## 最小可演场景

先用下列记录排除卡点，再写自然对白和动作。无需把所有字段原样展示给用户。

| 字段 | 内容 |
| --- | --- |
| 入口 | 何时、何地、谁找谁；发起者为何此刻需要对方 |
| 双方目标 | 公共要完成的事，以及各自可能不同的私下目的 |
| 信息与障碍 | 各自知道什么，不能直接说什么，为何不能一步完成 |
| 可参与动作 | 玩家能问、选、做、拒绝、交付或重新协商什么 |
| 关键往返 | 对方收到回应后如何改变下一句话或下一步动作 |
| 留下的变化 | 新信息、共同记忆、承诺、分歧或实际决定 |
| 结束条件 | 做到什么即可离场；如何回到阅读或公共流程 |

两项快速检查：删掉情话，两人还有什么事可做？删掉整段，后文有什么会改变？安静陪伴和生活闲谈也可以成立，但要说明其在当下关系中的具体作用。

## 让对话有继续的理由

按人物与场景选择一个主要来源即可。

- 共同任务需要协商做法，例如统一说辞、选一份礼物、准备出发。
- 同一经历记忆不同，双方有理由追问差异。
- 一方有具体请求，另一方有真实顾虑，需要讨价还价。
- 一件尚未解释的行为影响两人关系，需要说明或承担。
- 公开立场与私下目标不同，一句话同时处理眼前事与关系试探。

让对白承接玩家说过的内容。不要连续发问却忽略答案，也不要用一段长演绎吞掉所有互动入口。能拒绝的提问应有拒绝后的有效推进方式；规则用于提供表达方式，不把玩家真实情绪当作必须交付的答案。

## NPC 行为状态

对复杂 NPC 记录当前状态，简单场景用几句说明即可。

`故事时间/视角｜公开身份｜私人目标｜已知事实｜暂不可透露的事实及理由｜可回应行为｜状态改变条件｜退出条件`

主动行为须来自目标或已观察到的玩家动作。例如玩家提起一个未完成约定，NPC 才调整下一次准备；不要凭“温柔人设”在任何时刻随机送礼。

| 玩家反应 | 主持稿应准备的处理 | 避免的卡点 |
| --- | --- | --- |
| 沉默、尚未入戏 | 从抽象谈感受缩小到眼前可选动作；留时间；仍沉默则由 NPC 完成可独立部分 | 无限追问，等玩家必须说出指定台词 |
| 拒绝请求或示好 | 承认拒绝，按人设表达失望、改提条件或暂退；保留后续入口 | 把拒绝当作没听见，强行完成亲密动作 |
| 主动示好 | 回应具体行为，允许关系局部提前变化，保留尚未解决的事实矛盾 | 无视回应继续照念“你还不信任我” |
| 提前猜中 | 按角色知情范围承认、保留或反问；揭示重点转向理由和代价 | 编新事实否认，后文再自我矛盾 |
| 未执行关键动作 | 区分情感动作与必需信息；用其他可信渠道补足必要信息 | 要求玩家重演刚拒绝的动作才发线索 |

这些是编写响应的检查类别，不是任何 NPC 都要使用同一套温柔话术。骄傲、敌对或不善表达的人也可以维持可继续的场景。

## 选择与固定剧情

先确定某个选项究竟改变什么。

| 类型 | 主持稿写清 |
| --- | --- |
| 结局选择 | 各结果的条件、具体后文与演员执行区别 |
| 过程选择 | 哪些信息、关系或代价改变，何处汇合 |
| 表达选择 | 玩家可以认可、反对、沉默等；外部事件仍按既定原因发生 |
| 固定演绎 | 玩家主要观看或有限参与，不承诺不存在的分支 |

固定剧情必须能容纳不同立场。若剧情确定角色离开，可让玩家选择告别方式；不要宣称“你能决定他是否离开”却强行替玩家选定。肢体动作准备等价的口头或道具替代，拒绝动作不能被解释为玩家“不够爱”。

## 全桌与演员调度

把“谁在何处、占用哪位演员、其余人做什么”列在同一时间段。预计时长注明是排演估计，实际测试再记录耗时。

| 时段/触发 | 场地 | 演员与任务 | 参与玩家 | 其余玩家活动 | 超时或演员未就绪时 |
| --- | --- | --- | --- | --- | --- |
| 按本次流程填写 | 公共/私聊 | 避免同人同时两地 | 明确到角色 | 阅读、协作、其他交流或休息 | 可延后部分、替代入口和保留的关键信息 |

多人场景让非 CP 玩家拥有具体作用，如提供条件、提出异议、承担结果、完成合作动作或回应请求。只让大家围观轮流告白，不能直接算有效群像。

NPC 的全桌职责与恋陪职责分别核查；若同时需要，应调整顺序或配置。不要把“一名演员可随机补位”当作已经解决排班。音乐、物件、灯光有条件才使用；关键事实若依赖它们，准备故障时仍能理解的呈现。

## 玩家本与主持稿的同场校对

使用相同场景编号连接两侧。

- 玩家侧写当下所知、角色内目的、寻找对象或等待的信号，以及允许采取的行动。
- 主持侧写开场条件、演员所知、不可提前泄露的信息、动作与关键台词、不同回应、收束条件和下一场。
- 逐项检查玩家有没有读到触发提示、NPC 是否有空接、线索是否在所需时点出现、私聊所得如何进入公共剧情。
- 必需线索与可选亲密互动分开安排。玩家可以不参与某种亲密表达，故事仍应有合理路径继续。
