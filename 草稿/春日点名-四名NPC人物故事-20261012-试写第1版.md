四篇分别从 NPC 的视角叙述，每篇中的“你”指标题所示的 NPC。正文以代号指称其他角色。当前恋爱发生在玩家成年后的毕业班阶段。

## P1N 校草

你很少让人难堪。

谁忘了带讲稿，谁在台上念错名字，你都接得住。老师喜欢把麻烦事交给你，同学也喜欢。一件事情只要到了你手里，总会变得妥帖，好像它从来没出过差错。

P1 第一次和你熟起来，也是因为一份讲稿。

那天基金会要来拍照，韩成宰希望她讲讲被收养以后的生活。稿子印了三份，连停顿的位置都标好了。她读到第二段，手指停在一句话底下。

从前的生活只剩苦难。

你问她哪里不顺。她摇头，把那一页翻过去。

你便拿走讲稿，说现场流程有变，学生发言取消了。后来摄像的人找到你，你带他们去拍新落成的图书室。韩成宰问起来，你说设备出了问题，自己会处理。

到了放学，P1 在楼梯口等你。

“设备出了什么问题？”

“拍出来不好看。”

“谁不好看？”

你看她一眼。

“你不想笑的时候。”

她忍了忍，还是笑了。又从书包里拿出那份稿子，当着你的面，划掉了那句话。

“我爸爸会骑车带我去买早饭。”她说，“我妈妈总嫌他买多。我们家从前挺好的。”

你说，嗯，那就不念。

她低头继续改字，你在旁边等着。那天原本还有一场会，你迟到了十七分钟。

这是 P1 知道的你。会替人解围，偶尔说句不正经的话，连迟到也能解释得合情合理。

至于你为什么这么擅长善后，她当时并不知道。

你小时候，母亲常在饭桌上算账。你坐在她旁边做作业，听她翻纸，问她还要多久。她总说，等妈妈核完这一页。

她最后一次出门，也说很快回来。

后来来家里的人成了韩成宰。他带着花，握住你的手，说以后有难处就找他。大人们忙着感谢，你盯着他袖口的一点线头，想起母亲出门前说的话。

她要去问一个人，为什么孩子们的救助款会进私人诊疗账户。

那个人如今坐在你家的沙发上，劝你节哀。

你没有掀翻桌子。你给他倒了一杯水，又把杯柄转到他右手边。

等人都走了，你把母亲留下的账本收进书包。你逐渐查清，单凭一个孩子拿着几页纸去问话，什么都讨不回来。你需要有人替你开门，需要钱，也需要一个让韩成宰不敢挂断电话的身份。

这些东西，后来你都有了。

家族公司里的成年人替你出面，他们在文件上签名，你在电话另一端听汇报。韩成宰还把你当成优秀的学生，逢人便夸。你每次都恭敬地点头，问他最近身体好些没有。

他的诊疗账单，恰好由你的人经手。

P1 曾问过，你怎么好像什么都知道。

你说，校草也得干活，总不能全靠脸。

她白了你一眼，你很受用。她敢这样对你，你就愿意继续逗她。她叫你去买东西，到了校门口才发来消息，要多带三份。你已经买好了，连 P3 不喜欢的口味都换过。

你知道她会照顾家里的另外三个，也乐意在这些小事上纵容她。

有一回，她问你周末能不能空出一天。你以为终于轮到两个人独处，连要带她去哪里都想好了。她却说要去扫墓，想请你陪着。

“你妈妈那里，也去一下。”

你没接话。

P1 以为自己问得唐突，正要收回，你已经把手机上的安排全删掉了。

那天她蹲在墓前清理落叶，问你母亲喜欢什么花。你说都行。她抬头看你，等了一会儿。

你才重新回答。

你已经很久不向别人认真说母亲的事了。小时候那些等着吃饭的傍晚，说起来竟还有这么多。P1 没催你，擦干净旁边一块石头，坐下来听。

你想把这一天留得长一点。回去时故意走错一个路口，她识破了，也没有拆穿。

你确实爱她。爱到连她不高兴时的语气，你都愿意再听一次。

可你在另外一些事情上，依然照自己的办法办。

你想拿到清晨会的主册，想把自己的名字从那些批准采样的记录里删掉。母亲留下的证据替你打开了门，门里面的东西，你后来也想要。

奉还礼前，你安排了一辆车，足够两个人坐。司机问其他人怎么办，你说按原定安排。

你说这句话的时候，正在替 P1 挑一件御寒的外套。

她来找你时，你把外套搭在她肩上，告诉她出门以后别回头。她问 P2、P3 和 P4 在哪里，你说另有人接应。她没有动，把一张付款记录放在你面前。

她已经查过了。

你低头看见自己的授权，沉默了片刻。再开口时，你依然很平静，给她讲车会停在哪里，还有多久能离开。你把活下去这件事安排得周全，像当初替她处理那份讲稿。

P1 把外套脱下来。

“你什么时候开始觉得，我什么都能由你安排？”

你伸手接住，指尖碰到她的。她从前不会避开的。

“你跟我走。”你说。

她看了你很久，转身去找家里的另外三个。

你可以喊人拦住她。走廊另一端的人正在等你的手势，车也还没开。

你抬起手。

P1 听见动静，回头望你。隔着这么远，你仍然看清她在等什么。

你把手放了下去。

她没有回来。

## P2N 校医

P2 喜欢在校医室里待着。

她不总是来看病。有时候替别人取一份报告，有时候只是来问你下班没有。你给她留了把椅子，起初放在门边，后来她自己拖到了窗下。

她说门边总有人走来走去，坐不住。

你说这是校医室，当然有人看病。

“那我也有病。”

你抬头。

“不想回去上课。”

你把桌上的空白请假条压在手底下，她伸手来抽，你没松。拉扯了一会儿，她先笑了，说你小气。

每次她来，你都能把事情慢一点做完。她说话的时候，你听着；说累了，就让她安静坐一会儿。那些来来往往的学生和老师都知道，尹校医的脾气好，遇到怕疼的，还会蹲下来和对方说话。

你也曾经很耐心地等过另一种人。

那是在退伍以后。

韩成宰给了你四个家庭的资料。你逐一看完，亲自设计了那些后来被称作意外的死亡，又亲手把它们变成事实。

你记得每一个死者的脸。

有人到最后还在惦记家里的孩子。你听见了，当时没有停手。事情办完，韩成宰收养了四个孩子，得到感谢，继续做他的好人。

许多年后，其中一个孩子坐在你的窗边，拿着你给她倒的水，说今天过得真烦。

你没有忘记她是谁。第一次在登记表上看见 P2 的名字，你就认出来了。

她和父亲的眼睛很像。

你最初不愿同她聊家事。她说起父母，你便转身取东西，或者让她先把报告拿走。她有一阵以为你很忙，后来学会先问一句，现在能不能说话。

有一天，你正在等她来。

时间过了，她一直没有出现。你出去找，在操场边看见她坐着，手里拿着一张旧照片。她说梦见爸爸了，醒来却记不清他的声音。

你站在那里，听她讲那些已经断掉的日子。

她十二岁那年，父母答应她的事还有很多。她如今已经长大，有的自己做到了，有的仍旧想不通，为什么答应了她，却没有来。

你很想走开。

P2 把照片递给你，问他们是不是长得很像。

你看着照片，点头。

“像。”

她把照片小心收好，往旁边让了一点，给你腾出位置。你最终坐下了。

后来，她也照顾过你。

你忙起来常把饭放凉，她有次拎着两份晚饭过来，坐在那把椅子上盯着你吃。你说不用管自己，她把筷子递得更近，问你这句话平时是不是也拿来敷衍病人。

你认输，接过来。

饭不好吃。她买错了，又不肯承认，一口口吃得很艰难。你把她那份换走，她立刻问你什么意思，仿佛让人发现她不爱吃，也有损体面。

你说自己胃口大。

她满意了，开始讲白天发生的事。你听得走神，她敲敲饭盒，让你认真一点。

从那以后，你开始记她什么时候会来。有时她来晚了，你会问一句。问完又觉得自己可笑，你有什么资格要她交代去向。

你仍旧想听她回答。

你身上那种残忍，也没有因此消失。

校长派人来取走资料时，对方把堵在门口的 P2 推到了一边。你追出去，动手很快。等她跟出来，那人已经倒在地上，你还抓着他的衣领。

你听见 P2 叫你，才停下来。

她看你的目光，让你想起许多年前，那些人最后看你的时候。

你松开手，走回她面前。她的手腕红了，你想看看，她先退了一步。你在原地站住，半晌，把手收了回去。

秘密终究有被翻出来的一天。

P2 把四起案件的资料带进校医室，将几笔旧转账推到你面前。她问，父母出事以后，韩成宰为什么给你付钱。你看见她把资料按得很紧，纸角已经卷了。

你回答得很清楚。

“事情是我设计的。人也是我杀的。”

她像是没有听明白，让你再说一遍。

你又说了一遍。

窗外正好有人打球，球落在地上，一声接着一声。P2 低头翻资料，翻得很慢。到了父母那一页，她停了很久，问你，他们死以前有没有害怕。

你说有。

她的手从纸上滑下来。你往前迈了半步，她突然抬头，叫你站住。

那张你一直替她留着的椅子，就隔在你们中间。

她要你把事情写下来。谁下的命令，谁死了，写清楚，不准漏掉她的父母。

你坐下，拿笔。写到一半，习惯性地去拿旁边的水杯，想递给她。她没有接。

你把杯子放回去，继续写。

交给她的时候，你问了一句，以后还会不会来。

你甚至有点厌恶自己。她刚刚听你亲口承认杀了她的父母，你却已经在想，她以后还会不会坐在这里。

P2 没有回答。

她拿走供述，走到门口，停了一下。

“我会把这个交出去。”

“好。”

“另外三个人也会知道。”

“好。”

她回头看你，眼泪终于掉了下来。你听见她问，为什么偏偏是你。

那天你没有追出去。

下班前，你给那把椅子拧紧了松动的螺丝，把它留在了窗下。

## P3N 校霸

你第一次染头发，染得很糟。

后脑勺漏了一片，前面又亮得过分。你对着镜子拨了半天，觉得起码够凶，便戴上帽子去学校。走到校门口，才想起染头发就是为了让人看见，又把帽子摘了。

那天倒真没人堵你。

你松了一口气，回家把剩下半瓶染发剂收得很好。

你小时候并不威风。书包让人扔过，饭也被掀过，跑到老师那里，大多时候会得到一句，怎么又是你。

你后来学会先看鞋。走廊拐角露出熟悉的鞋头，你就换条路。绕远了会迟到，迟到又挨训，但至少这一回，饭能吃进肚子里。

最怕的是门被关上。

你被锁过一下午。起初拍门，后来不敢，怕门一开，他们觉得你吵，还要再打你。你蹲着等，把外面的脚步听了一遍又一遍。

后来终于有人来拿东西，门开了。

对方只问你怎么待在这里。

你很想骂他。你在里面待了一下午，嗓子都喊哑了，他问你怎么待在这里。

你最后只说，走错了。

从那以后，你开始练身体。起初撑不了几个就倒在地上，手臂抖得端不稳碗。第二天继续，等手臂不那么抖了，再多做一点。再后来，肩膀宽了，校服穿着发紧，才终于有人记住，惹你也会挨揍。

你很珍惜这点名声。

路上有人冲你喊一声校霸，你脸上不动，心里却觉得，这回该轮到别人绕路了。

可 P3 没有绕。

她第一次认真找你说话，是请你挪开脚。

你坐在器材室外，腿伸在过道上，挡着她搬东西。她手里一大摞纸箱，腾不出手拨你，也不肯喊别人来帮忙，就站在那里看着。

你收回腿，问她是不是没长嘴。

她说长了，怕一开口把你骂哭。

你乐了，起来帮她抱走一半。她跟在你后面，说刚刚还觉得你挺吓人。

“现在呢？”

“挺能搬。”

你一路把纸箱搬进教室，出来才反应过来，白给人干活了，连句像样的好话都没捞着。

下次她经过，你仍然问她有没有东西要搬。

P3 很快发现，你这人好使唤。

她想吃什么，你嘴上嫌远，走到路口又问她要哪一种。她说随便，你能站在柜台前跟她打十分钟电话，非得问出个确切答案。真买回来，她觉得不好吃，你也没脾气，把剩下的拿去自己吃。

她笑你，说校霸原来干这个的。

你问她，还想让校霸干什么。

P3 想了想，突然把手放到你面前。她没说话，你便也没再贫，低头擦了擦手心，才握上去。

走了一段，她说你牵得太紧。

你立刻松开。松得太快，她又瞪你，你只好重新伸手，小心拿捏那个分寸。你能拎起整袋器材，握一只手倒像从没学过。

你很喜欢和她这样走路。有人远远喊你去打球，你装没听见。P3 听见了，问你怎么不去。

“他们又不会跑。”

“我会？”

你看她一眼，没有答。

你偶尔也会把事情办坏。

她难受的时候，你急着替她解决。谁说话不好听，你先去找那人；她受了委屈，你就要她告诉你名字。有一天她发了火，问你能不能坐下听她把话说完。

你站在那里，半天才说，行。

你实在不知道，除了把人挡在身后，还能怎样让她好过。她把身边的椅子拉出来，你坐过去，一开始仍绷着肩。等她慢慢说完，你才发现，那些委屈有时候根本找不到一个能揍的人。

你便陪她坐着。

清晨会那场混乱里，你又挡到了她前面。有人扑过来，你把 P3 往身后带，脑子里只剩一个念头，不能让她挨着。

你带她退进一间屋子。后面的人撞上门，你从里面顶住，听见门锁猛地一响。

你的身体先僵了。

外面的声音还在，P3 就站在你身边，可你一时分不清自己究竟站在哪里。你低头找门把手，手却一直在抖，怎么握也握不稳。

“你受伤了？”P3 问。

你摇头，让她别看。

走廊另一头起了争执，堵门的人骂了一句，跑开了。P3 没有逼你回答，等你缓过来，才跟着你一起把门推开。走到外面，你仍旧不肯松开她，隔一会儿便回头看看刚才那间屋子。

后来只有你们两个人时，你把小时候那件事告诉了她。

说得很不耐烦。哪一年不记得了，谁锁的也不想提，总之都过去了，你现在一个人能打倒好几个。

P3 听完，说知道了。

你等着她夸两句，她却去把门开了一条缝，然后回来坐在你身边。

“这样行吗？”

你看着那道缝，点头。

她把手伸过来，这回你没有急着握。你先问她，会不会觉得自己很没用。

P3 把你的手拉过去，放在她膝上。

你低着头，过了一会儿，小声补了一句。

“这事别告诉别人。”

她答应了。

你靠过去，额头抵着她的肩膀，终于不用再盯着门。

## P4N 化学老师

你在校长办公室里待得越久，回教室就越客气。

有时候客气得过了头。学生打翻东西，你先说没关系；有人漏交作业，你说下次记得。P4 有一次看见你被撞掉一摞试卷，弯腰捡的同时，竟先给撞你的人道了歉。

她站在旁边，没说话，帮你把卷子捡起来。

你是韩成宰的手下。

这几个字在学校里很好用。别的老师找你帮忙，会先说校长那边等着；你手里的事情再多，听见这句话也得停下来。

韩成宰习惯当面叫你的名字，让你站着听。他发火时会砸东西，也会动手。第二天在走廊碰见，他照旧把手搭在你肩上，问昨天交代的事办好了没有。

你便答，办好了。

第一次挨打，你回到办公室，在洗手池前站了很久。有人进来，你赶紧打开水龙头，怕对方问怎么了。

后来不必等到洗手池前。你已经学会在推门出去以前，先把脸上的表情收好。

他偶尔会站在教室后门听课。有一回你说错一个字，抬头看见他，粉笔就在手里折了。学生们都停下笔等着，你只好擦掉黑板上的字，重讲一遍。

P4 是班长，来找你的次数多。有一回她送作业，你左手刚受过伤，接过去时没接稳，作业本散了一桌。你急着道歉，她却先把最上面的一本抽走。

“这个交错了。”

她把话题换得很快。你跟着她去看本子，才发现真是别的科目。她把那些本子重新摞好，靠着桌边放稳，问下次是不是还放这里。

你说，是。

她后来一直放在那里，离桌沿有一掌宽。你伸右手就能够到。

你忍不住注意起这些小事。她来交表格，会多留一会儿，问一道未必真不会的题。你讲着讲着，看见她早已经写出的答案，停下来问她，是不是拿老师解闷。

“你讲得好，想再听一遍。”

“这句话记过多少次了？”

“对别的老师没说过。”

她说得坦然，你反而先去看桌上的卷子。红笔握了半天，一个字也没批。

那天以后，你发现自己会等门口的脚步声。等到她来了，又觉得不该让她在这里待得太久。校长随时可能叫你，他手下的人也常过来，你怕她看见更多。

你在办公室里收着另一份东西。

那些真实的拨款记录，被改过的受害者名单，还有校长让人执行的指令。你用能接触这些文件的身份，一点点补全证据。留在他身边，就是为了把这些东西带出去。

每次受辱以后，你也会想，今天就走吧。

想过以后，还是把第二天的课备好。你要讲的内容很普通，烧杯怎么拿，做实验为什么要核对标签。韩成宰在背后做的事情太脏，站到讲台前，你至少还能把一节课讲清楚。

直到有一天，P4 在办公室外看见了他打你。

你先看到她，竟然比挨打更慌。你怕她进来，也怕她掉头就走。她一直信任自己的养父，你不知道该怎样向她解释，你在他面前为什么会变成这样。

P4 推开门，说班里有事，要请你过去。

韩成宰换了语气，问她怎么跑来了。她又说一遍，班里有事。

你从他身边经过时，他按了按你的肩膀。你本能地停住。

P4 在门外叫你。

“老师。”

你走了出去。

你们走到楼梯拐角，她才停下来，问这样的事有过多少次。你说没几次。她看着你，你又改口，说挺多的。

你想请她别对任何人提起。话说了一半，她眼睛就红了，你便再说不下去。

过了很久，她问你，要不要坐一会儿。

你们坐在楼梯上，她始终没劝你忍，也没急着替父亲解释。你第一次在受伤以后，和一个人待了这么久。

后来，她查到了自己家人的事。

P4 再来找你时，你把证据放在她面前，告诉她自己在查什么。她一页页看完，翻到四个孩子的名字，手停住了。你想解释，她抬手让你等一下。

你就等着。

她终于看完，把文件收拢，问哪些已经送出，哪些还差证人。你逐一告诉她。到了必须再回校长办公室的那一项，她握住你的手腕。

“还要回去？”

你说，要。

她没有松手。

你原本已经准备好了几句好听的话，想劝她先走。看着她的手，却一句也说不出口。那些文件里有她的父母，她有权知道你准备做什么，也有权觉得你的办法不好。

于是你把椅子拖近，将自己知道的事情重新讲了一遍。她认真听，提出另一个时间，问能否先把现有的证据送出去。

你们争了几句，最后改了安排。

临走以前，P4 把你歪掉的袖口理平。你看着她，没有像往常一样把手收回去。

“我会害怕。”你说。

她抬眼，等你继续。

你说的是回去见韩成宰，也说自己可能再一次停在门口。你已经很久没有把这件事说得这么难听，平时总能找到体面的解释。

P4 握住你的手。

“到时候，我再叫你。”

下一节课的铃响了。你们一起站起来，走到教室门口才分开。

你翻开课本，发现昨天备的那一页，角上还有 P4 帮你改过的一个错字。她坐在下面，仰着脸等你讲课。

你先把那个字重新写好。

这一次，粉笔没有折。
