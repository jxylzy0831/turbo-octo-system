# 《春日点名》

## 人物与代号规则

| 玩家代号 | 玩家姓名 | 专属恋陪代号 | 恋陪姓名与身份 |
| --- | --- | --- | --- |
| P1 | 恩书 | P1N | 车叙律，校草 |
| P2 | 知夏 | P2N | 尹时安，校医 |
| P3 | 多允 | P3N | 姜泰伍，校霸 |

P1 对应 P1N，P2 对应 P2N，P3 对应 P3N，P4 对应 P4N。同编号表示专属恋陪配对，开局尚未确立恋爱关系。

后文统一用上述代号。孩子们或玩家指 P1、P2、P3、P4；四名 NPC 指 P1N、P2N、P3N、P4N。跨配对的互动直接写出双方代号。

韩成宰是校长，也是四名玩家的养父，后文保留本名、校长或养父的称呼。旧案中的车雅琳为 P1N 的母亲，尹秀彬为 P2N 的姐姐，姜泰民为 P3N 的哥哥，徐正勋为 P4N 的父亲；后文以这些亲属关系称呼。

## 第一幕

### 文本内容

P1、P2、P3 和 P4 在十二岁左右失去亲生父母，先后被海原高中的校长韩成宰收养。P1 的父母死于火灾，P2 的父母遭遇车祸，P3 的父母溺亡，P4 的父母死于燃气事故。孩子们记得原来的家，也记得父母离开前的生活，只相信那些死亡确实是意外。

韩成宰这些年对孩子们都很好，一直被孩子们当成救了自己的恩人。

每个月，孩子们都要去合作诊所各抽一管血，父亲说是定期检查。P1 和 P2 曾按父亲安排休学，复学后与 P3、P4 一起在海原高中读毕业班。

孩子们都认识校草 P1N、校医 P2N、校霸 P3N 和化学老师 P4N。P1N 帮孩子们办过学生自治会的事，P2N 保管体检报告，P3N 常在校门口与孩子们碰面，P4N 带孩子们整理过基金会的活动材料。

P1 觉得 P1N 聪明，P2 与 P2N 说话比较自在，P3 发现 P3N 没有传闻中难相处，班长 P4 欣赏 P4N 肯认错。几次相处留下些好印象，还没人认真想过恋爱的事。

开学第一天，P1 带着 P2、P3 和 P4 来到学校。

### 读本后互动

韩成宰为孩子们安排开学小聚，接到电话后暂时离席。P1N、P2N、P3N 和 P4N 依次出场，各自坐到每名玩家旁边，用暧昧小游戏带大家熟悉起来。输的人回答与韩成宰有关的问题，玩家也能反问 NPC 与校长的往来。

P1N 善于逗人，打听韩成宰的来客与书房；P2N 温和细心，问到每月体检。P3N 好胜直爽，留意司机和旧仓库；P4N 认真克制，关心基金会的签名与授权。四名 NPC 对专属恋陪玩家的关注稍多，玩家此时只留下些好感。

聚会结束，韩成宰回来通知孩子们，七天后一起参加基金会的感恩活动。

## 第二幕

### 文本内容

P1 看见 P1N 抄过父亲的付款记录。P2 发现 P2N 在查父亲私人诊疗机构的样本编号，其中竟有自己的血样。P3 碰见 P3N 在旧地图上标父亲的去处，P4 则撞见 P4N 比对家里的签名与基金会表格。

P1、P2、P3 和 P4 交换见闻，才意识到小聚上的问题都有用处，P1N、P2N、P3N 和 P4N 都在暗中调查父亲。孩子们翻出历年报告，发现每月抽血的日期总与父亲的诊疗安排重合，决定分别找四名 NPC 问清楚，暂时不告诉韩成宰。

### 读本后互动

每名玩家都走过学生自治室、校医室、体育器材室和化学准备室，分别与 P1N、P2N、P3N 和 P4N 在小黑屋里单独接触。交谈中仍有小游戏和暧昧试探，专属恋陪的靠近更私人，调查也在继续。

P1N 提供早期筛选名单，P2N 查出部分体检报告没有对应检测，血样被送往韩成宰的私人项目。P3N 拿出哥哥的运输凭证，P4N 则找到附有陌生授权的照护表格。编号、地址、签名和付款日期相互关联，每名玩家都要向四名 NPC 核实。

P2 为弟妹的血样追问 P1N，P1 向 P2N 求助；P3 和 P3N 查运输路线，也与 P1N 争论遇到危险该先救谁。P4 负责整理线索，要求 P2N 与 P3N 检查记录，P4N 则请 P1 一起判断查档路线。

孩子们把材料放到一起，发现筛选名单的日期早于亲生父母出事。几次单独相处让好感更近了一步，可 NPC 为何调查、从什么时候开始利用孩子们，还没有回答。

## 第三幕

### 文本内容

韩成宰得知调查，把孩子们叫到一起，揭穿四名 NPC 的来意。P1N 的母亲、P2N 的姐姐、P3N 的哥哥和 P4N 的父亲都死于基金会旧案，四名 NPC 接近孩子们，是为了查韩成宰。

孩子们分别去质问，P1N、P2N、P3N 和 P4N 承认最初确实有目的。小聚上的回答、P2 的病历和家庭旧事，都被用来寻找证据。孩子们想起那些靠近，不知道有多少是为了让自己开口。韩成宰要求交回材料，P1 却带着 P2、P3 和 P4，用家中备用钥匙打开档案柜，按编号找到了原始附件。

### 读本后互动

孩子们共同核对四起家庭事故。九至七年前，韩成宰先从公益体检资料中按血型及相关遗传标志筛出 P1、P2、P3 和 P4，再安排毁掉孩子们的原生家庭。基金会随后出面救助，韩成宰取得了收养机会。付款、交接和录音记录，把所谓意外与他的指令连到了一起。

韩成宰一直怕死，相信诊所兜售的年轻血续命疗法，也相信清晨会所说的爱能提高血液能量。每月抽走的一管血用于筛查和私人续命项目；长期优待孩子们，也是他取血计划中的安排。

最近韩成宰的健康恶化，诊所兑现不了承诺，清晨会便提出最后一次奉还礼。七天后的感恩活动里，P1、P2、P3 和 P4 将被取血献祭，文件连死亡后的处理都写好了。

P3 提出亲手杀死韩成宰，P1 想先把弟妹带出去，P2 要公开诊所做过的事，P4 坚持把四起案件全部查清。孩子们都想报仇，暂时争不出同一个办法，却决定不再把材料交回父亲手里。

## 第四幕

### 文本内容

六年前，P1N 的母亲审核基金会账目，发现公益款在支付韩成宰的私人诊疗。P2N 的姐姐查到样本被挪用，P4N 的父亲发现纯净度报告被伪造，P3N 的哥哥帮助转移受害者和资料。P1N 的母亲、P2N 的姐姐、P4N 的父亲与 P3N 的哥哥进一步查到四起家庭案件，随后遭到韩成宰清理。P1N 的母亲和 P2N 的姐姐遇害，P4N 的父亲被栽赃迫害致死，P3N 的哥哥死在仓库清场中，还被写成纵火者。

P1N、P2N、P3N 与 P4N 各自保存了一部分家人的遗物，后来借孩子们接近韩成宰。在调查中，四名 NPC 与每名玩家都开始有了私人交情。

P4N 当年在基金会做临时协助。P4N 的父亲遭到威胁后，P4N 运送过被限制自由的人，最终仍没救下父亲。P4N 回校后受韩成宰胁迫，汇报过孩子们的动向，导致一次查档被截住。

玩家要问清四名 NPC 的过去，互相验证证言，也要谈清接下来的关系。孩子们已经失去对养父的信任，还不知道能不能把自己和家人的性命交给这些曾经利用过自己的人。

### 读本后互动

每名玩家再次走遍四间小黑屋，与 P1N、P2N、P3N 和 P4N 分别长谈。这一轮谈家人、亏欠和以后，专属恋陪可以有亲密接触；NPC 与其他三名玩家只通过交谈和选择拉近关系。

P1 去见 P1N，要求他讲清最初如何利用自己。P1N 道歉，想牵住她，承诺带她离开，P1 仍要问弟妹怎么办。到了 P2N 那里，她才说出自己也会失眠，也怕救不下家人。P2N 记下她的求助，往后她可以像找哥哥一样来找他。P3N 平时总嫌 P1 管得多，这次却请她撤离时给自己留个位置，他也想有个能回的家。P4N 把路线交给 P1 审定，接受她指出的错误，等她决定怎样带家人出去。

P2 取回病历，要求 P2N 以后说明调查用途。P2N 承认自己怕失去她，也怕再拿关心当借口，P2 若愿意留下，他才抱住她。P2 向 P1N 追问抽血的去向，要求兑现帮她查清的承诺，P1N 交出诊所线索，避开她的目光。P3N 听见 P2 答应为 P3N 的哥哥作证，第一次叫她姐姐，求她以后别再独自去诊所。面对 P4N，P2 不肯只收一句道歉，要求他找到曾被送走的受害者；P4N 把接应名单交给她，接受她监督自己还债。

P3 与 P3N 争论报仇之后还要不要活着离开。P3N 想抱她，又怕自己根本回不来，P3 要求他先答应回来，再让他靠近。到了 P1N 面前，P3 责怪他总让别人冒险；P1N 问她杀掉校长后，谁照顾 P1、P2 和 P4。两人争执许久，终于说出各自最怕失去谁。P2N 讲姐姐死后，自己靠着没看完的病人撑过了那些日子，P3 与他约好都要活着回来。P4N 听 P3 讲小时候怎样等溺亡的父母回来，也讲当年营救自己父亲失败的事。P3 希望以后能再有人听她讲父母，P4N 答应了。

P4 去找 P4N，想替他删掉不利的记录。P4N 拒绝，把自己的参与也写进证言。P4 曾坚持让所有作恶的人留下名字，现在却想让老师例外。P4N 签完字，才问 P4 是否还愿意靠近自己，P4 若伸手，他便拥抱 P4。P1N 交出母亲的账目，请 P4 继续补全受害者的名字；P4 要求他也接受同样的追问。P2N 请 P4 核对自己的证言，约好将来发现他做错事，也照样指出来。P3N 请 P4 替哥哥洗掉纵火者的污名，P4 让他把自己的名字也写进证言，以后还有属于 P3N 的人生。

P1 查到匿名资助方属于 P1N 家族的公司，拿付款指令质问 P1N。他承认半年前借家族公司控制资金，让成年管理人员替自己出面，靠母亲留下的罪证和诊疗付款胁迫韩成宰。校长一直以为下令的是这家公司的管理层。

P1N 最初为了报仇，后来允许采样继续，压下新的伤害报告。他准备夺取主册，删掉自己的罪行，再接管清晨会。留给 P1 的退路只有她一个人，P2、P3 和 P4 被留下，他可以接受。

P1 把这个安排告诉 P2、P3 和 P4。P2 拿着空白报告问 P1N，他曾答应查清抽血用途，为什么又批准采样。P3 追问，P1N 刚才还在问谁照顾她的家人，为什么自己却能接受她去死。P4 把刚补全名字的账目放回 P1N 面前，要他连自己的罪行一起留下。P1N 不能再只向 P1 解释。

P2N 确认 P1N 批准继续收样的记录，P4N 拿出延迟公开的指令，P3N 承认 P1N 劝过自己独自报复。孩子们把这些材料一并交出去，先核实证言已经送达，再安排证人撤离和外部救援。P3 与 P3N 约好，活着出去以后去看海。

## 第五幕

### 文本内容

七天过去，P1、P2、P3 和 P4 来到感恩活动现场。孩子们已经把材料副本送往外部，也与 P2N、P3N 和 P4N 约好了接应，P1N 却没有按时出现。

韩成宰拿出孩子们过去写的感谢信，让孩子们准备感恩发言。P1、P2、P3 和 P4 知道接下来要发生什么，仍坐在养父身边，等待知情者走到出口。

### 读本后互动

P1 问起亲生父母的死，韩成宰就以多年的抚养要求孩子们服从。P2 拿出样本登记，P3 放下事故文件，P4 问兄弟姐妹的名字为什么会在献祭名单上。校长承认自己想活，认定孩子们应当愿意救他。孩子们拒绝取血，P3 打开外侧的门。

P1N 带着主册回来，已经受了重伤。他擅自去取原件，想删掉自己的记录，被韩成宰发现，P1N 与校长在争夺中撕破脸。校长这才知道一直命令自己的人是谁。P1 叫来救援，没有替 P1N 藏起罪证，P2、P3 和 P4 也要求 P1N 讲清那份只留 P1 一人的逃生安排。

P4N 接过主册，交回韩成宰，暂时稳住校长。等知情者走到出口，P4N 才说明副本已经送出，连自己的证言也在其中。韩成宰想把 P4N 拖进内室封口，P4 与 P3N 赶去接应。P2N 护送知情者时遭袭，P2 带着联系好的救援去接 P2N。

P3N 还想返回内室找校长，P3 叫住他，撤到外侧的知情者还等 P3N 带路。若 P3N 肯回来，撤离可以继续；若仍独自报复，他会被困在追赶中。P4N 能否脱离内室、P2N 能否得到及时救治，也取决于此前准备的接应有没有到位。

外部救援赶到现场。接应到位时，P1、P2、P3 和 P4 离开，韩成宰被控制；若通路和联络接连失守，未能撤离的孩子仍会落在校长手里，献祭也未必能全部阻止。

## 第六幕

### 文本内容

P1N 伤得太重，救治没能挽回。他想给 P1 留一封信，还有些犯罪记录没有交代。

孩子们也收到 P2N、P3N 与 P4N 的消息。得到接应的 NPC 活了下来，受伤的 NPC 仍在救治；未能撤离的 NPC，留下了最后可以说话的机会。

### 读本后互动

P1 让 P1N 补全签过的授权。他握不住笔，她就记下人名和日期。她可以听完他的私人告别，也可以先追问其他受害者，但 P1N 最终死亡，证言与私人信分别留下。

P2N 重伤后记忆混乱，有时把 P2 当成求助的学生。P2 重新说自己的名字，让他停止替别人操心。救援及时，两人以后一起面对恢复；若救治来迟，这次重新介绍便成了告别。

P3N 若跟着 P3 撤离，两人仍有机会兑现去看海的约定；若独自报复受了致命伤，P3 要面对他没有回来。他可以讲清自己的决定，却不能把后果归给 P3。

P4N 若被接出内室，便活着接受调查；若仍被校长控制，会遭注射封口。P4 处理他的私人信和完整证言，可以答应与他在一起，也可以拒绝。写下的罪责仍要交出去。

专属告别后，玩家也去见其他 NPC。P1 问 P2N 下次还能不能求助，P2 替 P3N 保管 P3N 的哥哥的澄清证言，P3 再给 P4N 讲一件父母的小事，P4 替 P1N 把未交代的受害者补进账目。活着的 NPC 亲自回应；若 NPC 已经死亡，玩家把没来得及说的话写进告别信。

## 第七幕

### 文本内容

离开学校以后，P1、P2、P3 和 P4 要继续追查亲生父母的死，也要面对 P1N、P2N、P3N 和 P4N 的结局。韩成宰的抚养不能抵掉四起谋害，P1N 的死亡也没有让他批准过的伤害消失。

### 读本后互动

各 NPC 角色返场，随后谢幕。
