# 现代新本十一人功能表 v1

## 暂定名称

《撤回之前》

## 当前创作假设

- 五名玩家，五名专属恋陪 NPC，一名幕后场控。
- 全员性别暂不锁定，关系称谓均可在定角后调整。
- 题材采用现代现实悬疑与情感沉浸，故事发生在一间即将举行封闭首映的放映厅。
- 预计时长六至七小时。前半程有重逢、试映和工作往事，后半程进入证言争议、旧案真相与关系选择。
- 玩家拥有真实决定权，但任何决定都不能跳过角色已经造成的后果。

## 一句话故事

五名纪录片制作成员带着各自的爱人，参加纪录片《十七层》的最后一次封闭试映。影片调查三年前的栖海公寓火灾。零点一到，五个章节将分别上传。五名玩家此时才知道，每一章最关键的材料都来自自己的爱人，而这些材料有人已经要求撤回，有人是在恐惧中授权，还有人愿意用自己今后的人生换它公开。

## 共同事件

三年前，长租企业安栖生活把一栋旧办公楼改造成栖海公寓。企业使用智能门禁管理住户，拖欠房租、进入纠纷名单或被系统误判的住户，门卡可能被远程限制。

火灾发生当晚，十七层断电。消防通道里有一道需要通电解锁的门。官方调查把主要责任归于违规用电和住户逃生混乱，安栖生活随后与受害者家属和解。

五名玩家共同制作纪录片《十七层》，掌握了五类彼此补足的材料。单独一份只能证明某个人做错了事，五份放在一起，才足以证明企业长期知道门禁存在危险，又在火灾后修改记录、诱导证词并迫使受害者签署保密协议。

五名 NPC 都与材料直接相关。他们既受到安栖生活伤害，也在火灾当晚做过会被公众误解、追责或攻击的事。纪录片若公开，企业很难继续脱身，五名 NPC 的生活也会被永久改变。

## 主题问题

故事持续追问一件事。

当一个人把选择权交给爱人，对方应当怎样使用它，又应当在什么时候归还。

五条关系分别处理撤回、委托、隐瞒、沉默和承担。结局不宣布统一答案。玩家通过保留、删改或公开自己负责的章节，交出各自的回答。

## 五份材料怎样拼成真相

| 章节 | 材料 | 单独公开时的指向 | 与其他材料合并后的意义 |
|---|---|---|---|
| 第一章 | 住户偷拍视频与原始采访 | 住户曾经发现门禁异常 | 企业在火灾前已经收到多次警告 |
| 第二章 | 产品会议录音与测试报告 | 技术人员知道断电风险 | 管理层为了压缩改造费用拒绝更换门锁 |
| 第三章 | 火灾当晚的门禁后台记录 | 某个账号曾经远程锁门 | 账号被企业借用，操作时间后来遭到篡改 |
| 第四章 | 和解谈判录音与保密协议 | 家属接受赔偿并改变证词 | 企业利用治疗费和债务迫使家属沉默 |
| 第五章 | 一段未公开的消防通道录音 | 有人为了救一名爱人放弃了另一群人 | 门后的死亡与企业违规、现场选择同时有关 |

## 六幕体验安排

### 第一幕 最后一场试映

- 五名玩家重聚，介绍三年制作过程和各自负责的章节。
- 五名 NPC 以伴侣、受访者或协助者身份陆续出现。
- 前半段以工作旧事、拍摄花絮和关系互动为主，让五对人物先拥有可喜欢的生活。
- 幕末第一次播放故障。系统提示五个章节的授权状态均存在争议。

### 第二幕 五份授权

- 玩家分别读到自己与 NPC 当年签署、录制或口头约定的授权材料。
- 公共桌面开始争论旧授权是否仍然有效。
- NPC1 与 NPC2 完成第一轮私聊，撤回和预先委托首先发生冲突。
- 幕末发现有人删除过撤回邮件。

### 第三幕 被删掉的人

- P3 恢复部分后台数据，团队怀疑内部有人替安栖生活修改材料。
- NPC3 私聊后交出恢复密钥，P3 的旧邮件进入公共证据。
- P4 发现五份材料都有亲密关系介入，开始重新检查法律和伦理风险。
- 幕末空白明信片出现，P4 意识到自己错过了一次求救。

### 第四幕 沉默的价格

- 和解录音公开，玩家知道家属改变证词的现实条件。
- NPC4 完成两轮私聊。公开边界从全有或全无，变成条款、身份和医疗隐私分别决定。
- 安栖生活发来停止发布的正式函件，并愿意赔偿团队全部损失。
- 幕末 P5 的音轨中出现缺失九十秒。

### 第五幕 门的两边

- 场控只播放声音，不呈现火灾画面。玩家依靠脚步、门禁提示音和对讲机判断现场。
- NPC5 与 P5 分别说明自己当晚能够看见和听见的范围。
- 五份证据拼合，企业责任成立。NPC5 的关门选择也无法被删去。
- 每名玩家拿回自己章节的最终处理权。

### 第六幕 撤回之前

- 五对人物进行最后一次短私聊，每组严格限时。
- 玩家逐章选择原样公开、删改后公开、定向提交或撤回。
- 系统按五个决定生成不同的上传结果，不评价谁更勇敢。
- 结尾回到放映厅正常白灯。五名 NPC 可以继续留下，也可以按照各自关系结果先行离场。

## 私聊调度原则

- 同一时间最多进行两组私聊，至少三名玩家留在公共桌面。
- 每次私聊控制在八至十二分钟。最后一轮每组不超过六分钟。
- NPC 以规定动作收尾。交还授权书、放下恢复密钥、撕开协议副本、交出未剪音轨等动作完成后，场控即可切换提示音。
- NPC 不根据玩家哭泣程度延长场景。需要安抚时先退出角色，安全高于流程。
- 每条恋陪线至少有一次公共互动，避免感情只存在于小房间。

## 五条线的公共交叉

| 交叉关系 | 作用 |
|---|---|
| P1 曾拍下 NPC4 的和解采访 | P4 可以质疑 P1 是否利用受访者脆弱状态 |
| P2 的内部录音由 NPC3 转交 | P2 与 P3 会争执材料来源和删改责任 |
| P3 恢复的日志证明 NPC5 没有远程锁门 | P5 欠 P3 一次事实上的澄清 |
| P4 起草过 NPC2 的匿名协议 | NPC2 撤回后，P4 必须面对自己设计的授权边界 |
| NPC1 的偷拍视频拍到 P5 进入消防通道 | 第一章与第五章互相证明，任何一章撤回都会改变公共判断 |

## 当前版本必须守住的边界

- 企业责任不能洗掉个人选择，个人选择也不能替企业承担全部责任。
- 五名 NPC 都有自己的目标，不能只负责爱玩家、原谅玩家或替玩家受罚。
- 五名玩家的最终决定应当改变发布内容和关系位置，不能由固定结局宣布所有选择无效。
- 不用绝症、失忆、人格分裂或突然出现的遗嘱推动关键转折。
- 火灾只写人物能够听见、看见和做到的事，避免用大量伤亡描写制造情绪。
- 恋陪演员不得以分手、自伤或公开羞辱强迫玩家选择。

## 下一轮需要确定

- 城市气质和故事发生年份。
- 五名玩家与 NPC 的性别、年龄和职业是否固定。
- 火灾是否保留，或更换为医疗、校园、平台劳动等共同事件。
- 最终发布采用五章独立决定，还是要求五人共同表决。
- 作品希望保留多少案件推理，情感沉浸和调查各占多长时间。
