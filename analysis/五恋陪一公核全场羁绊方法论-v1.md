# 五恋陪一公核全场羁绊方法论 v1

## 方法的用途

这套方法服务于五名玩家、五名专属恋陪 NPC 和一名公共 NPC 的情感剧本。

五名玩家拥有不同的主要体验。有人负责在公共场合输出和谈判，有人掌握秘密与把柄，有人承担高理解成本和高痛选择。剩下的位置可以偏向关系丰收与逆风翻盘。五份体验共同进入一件公共事件，最终产生全场羁绊。

公共 NPC 在下文简称公核。公核可以兼任主持和部分场控工作，但进场表演期间必须有人代管固定音画信号，或提前把该段音画设成顺序播放。

## 从《流氓叙事》中提取的结构

### 玩家得到的体验并不相同

《流氓叙事》手册明确给角色排过理解成本。程聿怀最复杂，事业线与信息量最高。黛利拉理解成本较低，恋陪体验更集中。中间角色分别承担记者职业、豪门伪装、成长、理性决策和关系联动。

角色体验的公平不靠页数相等，也不靠每个人哭同样久。每名玩家都要在自己擅长的体验上拥有一段别人无法替代的高光。

### 专属恋陪也进入公共场

阿奇在公开场合负责活跃气氛、参加游戏、询问其他玩家，也会借一句看似属于黛利拉的话向程聿怀传递只有两人听得懂的信息。羌青瓷既陪程聿怀，也会主持测试、挖掘其他情侣的认知偏差，并在欢乐环节埋下后期反转。

恋陪 NPC 若只在小房间里爱自己的玩家，五对关系会逐渐分裂成五个节目。恋陪必须对公共事件有职业能力、立场或行动。

### 奥丁用不同关系收住全场

奥丁给玩家的关系不平均。

| 对象 | 奥丁给予的关系 |
|---|---|
| 黛利拉 | 女儿与继承人 |
| 以撒 | 儿子，也是唯一会为冷笑话发笑的人 |
| 缪宏谟、程走柳 | 一起行动的朋友，想劝她们活下去 |
| 蒋伯驾 | 从敌意到认可，最终想收进家人范围 |
| 程聿怀 | 能共同承担大事的同行者 |

这种关系有远近、有变化，也有误解。玩家不会觉得公核在机械端水。

### 欢乐环节提前制造共同记忆

轮盘、背对背答题、线索卡和魔术承担了三件事。玩家公开说出关系认知，其他人得到可以调侃和追问的信息，后期真相又能改写这些答案。

欢乐环节因此属于主线。删掉它，后面的痛感会失去共同经历。

## 总体模型

这套结构可以概括为一核、五纵、双环。

### 一核

公核提供共同地点、集体称呼、活动规则和早期安全感。五名玩家都与公核有一笔独立关系，可能是一份恩情、一场误解，也可能共同犯过一次错。

公核不能掌握全部真相。公核应当拥有一个会伤到全场的盲点。后期五名玩家需要离开公核的保护，自己作出决定。

### 五纵

每名玩家与专属恋陪 NPC 构成一条纵向关系。每条关系至少经历四次变化。

| 阶段 | 关系任务 |
|---|---|
| 初见或重逢 | 让玩家知道对方怎样爱，也知道这份爱有什么条件 |
| 共同办事 | 情侣一起完成会影响公共事件的行动 |
| 权力变化 | 一方获得秘密、决定权或离开的能力 |
| 最终选择 | 双方当面处理此前留下的后果 |

### 双环

内环由五名玩家和公核组成。它负责共同记忆、公共任务和全场立场变化。

外环由五名恋陪 NPC 组成。每位恋陪至少与另一名玩家存在因果关系，也要和另一位恋陪发生一次合作、冲突或旧事回收。

外环不能成为演员私下热闹、玩家毫不知情的暗线。恋陪之间的行动最终要回到玩家桌面。

## 五种玩家体验合约

写人物以前，先给五名玩家各写一份体验合约。合约描述玩家在桌上会做什么，以及离场以后最容易怎样介绍自己的角色。

### A 位 权力输出与爽谈

玩家离场后的描述应当接近这一句。

我在场上拥有资格、筹码和话语权，很多事情要经过我的同意。

| 设计项目 | 要求 |
|---|---|
| 公共权力 | 能批准交易、改变规则、调动资源或代表某个群体发言 |
| 爽谈来源 | 对手承认其资格，桌上其他人也确实需要其决定 |
| 恋陪方式 | 恋陪托举玩家的能力，同时敢在玩家滥用权力时当面反对 |
| 高光形式 | 谈判、公开陈述、定条件、逼对手让步 |
| 必要代价 | 玩家获得的每项利益都会让某段关系承担后果 |

爽感不能只靠 NPC 夸赞。玩家必须握有别人拿不走的资格，并能用它改变现场结果。

### B 位 情报庄家与把柄感

玩家离场后的描述应当接近这一句。

我知道每个人在怕什么，也能决定一部分秘密何时出现。

| 设计项目 | 要求 |
|---|---|
| 信息权力 | 掌握四名玩家各一条能改变判断的秘密 |
| 使用方式 | 每条秘密都有公开、交换、保护和误导等不同用途 |
| 恋陪方式 | 恋陪知道玩家缺失的那一部分事实，双方既合作也互相防备 |
| 高光形式 | 点破谎言、交换证据、设局、选择保护谁 |
| 必要限制 | 信息分幕解锁，其中至少一条早期判断存在偏差 |

把柄位不能开场获得完整答案。完整答案会让玩家变成旁观者。好的情报位知道得比别人多，又始终差一块足以改变自己判断的材料。

### C 位 高痛决策与事业负担

玩家离场后的描述应当接近这一句。

我有能力救很多人，也亲手伤害了最爱我的人。

这个位置可以借鉴程聿怀的痛感来源。玩家能力很强，承担公共目标，也习惯替身边人决定。后期痛感来自玩家亲手作出的选择，选择当时有充分理由，后果无法撤回。

新角色需要换掉程聿怀的具体机关。

| 可以保留 | 必须更换 |
|---|---|
| 高能力带来的傲慢 | 催眠与失忆 |
| 公共使命挤压亲密关系 | 爱人长期假装敌人 |
| 玩家亲自作出伤害性选择 | 死后才知道爱过 |
| 后期重新理解自己的保护欲 | 双重身份与替身秘密 |

恋陪 NPC 要在玩家活着、清醒并拥有反驳能力时与他对质。NPC 可以理解这项选择，也可以拒绝原谅。痛感由责任产生，不靠突然死亡替人物结账。

### D 位 关系丰收与被坚定选择

玩家离场后的描述应当接近这一句。

我进入每个人的故事，也有人在人群里一直选择我。

| 设计项目 | 要求 |
|---|---|
| 羁绊密度 | 与公核和其余四名玩家都有可回忆的具体事件 |
| 恋陪方式 | 恋陪公开偏爱，私下又尊重玩家与朋友、家人的关系 |
| 高光形式 | 认亲、重逢、替朋友说话、把分裂的人重新叫回桌面 |
| 必要代价 | 玩家无法同时保住全部关系，需要承认某段关系已经改变 |

这个位置承担全场情感回收，却不能成为传话工具。玩家本人要做过让别人愿意回来找他的事。

### E 位 逆风翻盘与行动破局

玩家离场后的描述应当接近这一句。

所有人起初都低估我，最后由我完成别人办不到的事。

| 设计项目 | 要求 |
|---|---|
| 初始处境 | 权力低、名声差、身份受限，或被公共叙事误解 |
| 能力伏笔 | 早期行动中已经使用过关键技能，后期放大用途 |
| 恋陪方式 | 恋陪不替玩家解决问题，负责提供进入行动的机会 |
| 高光形式 | 反制、救援、夺回证据、改变现场空间或规则 |
| 必要代价 | 翻盘只能解决眼前危机，不能抹掉玩家过去的错误 |

这个位置适合偏行动和成就感的玩家，能够调节全场持续沉浸造成的疲劳。

## 五席体验配重表

下表用于首轮设计，不是最终分角问卷。分值一至五，只表示相对重心。

| 体验维度 | A 权力输出 | B 情报庄家 | C 高痛决策 | D 关系丰收 | E 逆风翻盘 |
|---|---:|---:|---:|---:|---:|
| 公共发言 | 5 | 4 | 4 | 4 | 3 |
| 信息掌握 | 3 | 5 | 4 | 2 | 3 |
| 恋陪浓度 | 3 | 3 | 4 | 5 | 3 |
| 道德负担 | 2 | 3 | 5 | 3 | 4 |
| 全场羁绊 | 4 | 5 | 4 | 5 | 3 |
| 行动权限 | 5 | 3 | 3 | 2 | 5 |

公平检查关注两件事。每名玩家有没有独占的高光，以及他的选择能不能改变其他人的体验。总字数和私聊分钟数允许不同。

## 五名恋陪 NPC 的差异化动词

五名恋陪不能都写成等待、守护和牺牲。给每名恋陪分配一个主要动词，演员才会提供不同的关系手感。

| 对应席位 | 恋陪主要动词 | 现场表现 |
|---|---|---|
| A 位 | 托举 | 帮玩家获得发言资格，也会在公开场纠正玩家 |
| B 位 | 试探 | 交换信息、藏一部分事实，观察玩家保护谁 |
| C 位 | 追责 | 要求玩家直面选择造成的伤害，不负责轻易原谅 |
| D 位 | 偏爱 | 在公共场明确选择玩家，私下允许玩家拥有其他重要关系 |
| E 位 | 并肩 | 提供行动入口，与玩家一起冒险，结果由玩家完成 |

每名恋陪还要满足四项最低要求。

- 在公共场完成一次与爱情无关的有效行动。
- 一场私聊结束后，公共桌面的信息、权力或计划发生变化。
- 与公核有一段独立关系，不能只通过玩家认识公核。
- 影响另一名玩家的一次重要决定。

## 公核怎样拉住五个人

### 公核要给五个人五种关系

可以按下面的关系类型分配，具体人物再调整。

| 玩家 | 与公核的关系 |
|---|---|
| A 位 | 公核曾把公开权力交给他，现在会监督他怎样使用 |
| B 位 | 公核知道他在收集秘密，两人互相利用也互相提防 |
| C 位 | 公核曾被他的决定伤害，仍承认他对集体有价值 |
| D 位 | 公核与他最像家人，能够暴露公核柔软和自私的一面 |
| E 位 | 公核早期低估过他，后期必须把最后一次行动交给他 |

公核对每个人都要有一句只有两人懂的话、一件共同做过的事，以及一处没有解决的旧账。

### 公核需要掌握共同空间

公核最好拥有一处所有人都来过的地方。它可以是诊所、地下电台、法庭后厅、列车餐车、拳馆或谈判所。这个空间提供集体称呼、日常规矩和共同物件。

玩家喜欢公核，往往始于很小的动作。公核知道谁不吃什么，记得谁第一次来时坐在哪里，也会在别人拿玩家的伤病或出身开玩笑时立刻制止。

这些细节必须在前半程出现。结尾临时宣布公核爱所有人，无法补出羁绊。

### 公核主持欢乐，也暴露关系

公核设计的游戏要完成一项公共任务。可以让情侣回答对同一段往事的不同记忆，也可以让玩家互相分配资源、评价谁最可信。

每一轮欢乐至少释放一条后期会改变含义的信息。玩家当时笑过，后面才有机会意识到自己笑的是一段误解。

### 公核必须失去一次控制

前半程由公核维持秩序。后半程要出现一件公核无法解决的事。可能是他的秘密公开，也可能是五名玩家发现公核一直替他们决定。

这一刻以后，公核停止给答案。五名玩家需要自己讨论、结盟和承担后果。公核仍在场，但不再拥有替全场作决定的资格。

### 公核不必死亡

公核死亡能快速统一情绪，也容易重复《流氓叙事》的集体牺牲。新本可以让公核活着面对五个人的判断。被自己养大、保护或利用过的人共同拒绝他的安排，也能产生足够强的场面。

## 让私人戏进入公共桌面的转移规则

### 每场私聊必须带回一样东西

私聊结束后，玩家至少带回下面一种结果。

- 一份能够公开或销毁的证据。
- 一项只有玩家能使用的权限。
- 一句需要向另一名玩家兑现的承诺。
- 一笔此前不知道由谁承担的债。

玩家可以暂时隐瞒，故事仍要让这件东西有机会进入公共桌面。

### 每个大秘密至少影响三个人

一个重要秘密应当同时改变秘密拥有者、对应恋陪和第三名玩家。只伤害一对情侣的秘密属于个人支线，不能承担全场反转。

### 每名玩家同时握住救人与伤人的能力

五名玩家之间需要建立交叉依赖。

| 玩家持有的东西 | 对另一人的作用 |
|---|---|
| 一份证据 | 能洗清甲，也会暴露乙 |
| 一项权限 | 能放走甲，也会让乙失去谈判筹码 |
| 一段证词 | 能完成公共真相，也会摧毁某段私人关系 |
| 一次沉默 | 能保住爱人，也会让另一名玩家继续背锅 |

如果玩家只需要处理自己的恋爱，他就没有进入群像。

### 恋陪要跨对行动

每名恋陪至少有一次公开帮助或阻拦别的玩家。跨对行动必须来自职业、旧事和立场，不能靠暧昧或临时热心。

## 建议的七段现场节奏

### 第一段 公核收人

公核逐一欢迎五名玩家，用五种不同关系介绍他们。玩家得到共同称呼，也得到一件能在后面回收的物品。

### 第二段 欢乐测量

情侣参与公共游戏。五组问题测量不同内容，包括权力、信任、记忆、归属和承担。答案差异成为后期材料。

### 第三段 恋陪给权

五组第一次私聊。NPC 不急着告白，先给玩家证据、权限或任务。玩家回桌后能够参与公共事件。

### 第四段 第一次交叉使用

A 位谈判，B 位开始交换秘密。C 位为了公共目标作出第一次伤害性决定。D 位尝试保住关系，E 位第一次显示关键能力。

### 第五段 公核失控

公核的盲点或旧错公开。五名恋陪各自站到公共事件中，玩家发现专属爱人也有不围绕自己的目标。

### 第六段 第二次私聊与当面对质

恋陪处理前半程发生的选择。C 位在这里承受主要痛感，B 位得到最后一块未知材料。其他位置分别确认自己要保住什么。

### 第七段 五种高光与共同余波

五个高光采用不同动作。A 位完成公开谈判，B 位决定秘密顺序，C 位承担无法撤回的责任。D 位把分裂的人叫回现场，E 位完成行动破局。

结局分别交代五对关系，再让五名玩家共同面对公核。公共事件的结果由五种选择共同生成。

## 公核兼任幕后场控时的执行办法

同一名演员同时表演和控灯光音乐，必须采用分段出场。

- 公核在场时只使用提前排好的顺序音频，避免临场找曲。
- 公核离场后进入固定读本或私聊窗口，再处理灯光、音乐和道具。
- 需要公核在台上完成的重要音画节点，由一名当前没有私聊任务的恋陪按单键触发。
- 所有灯光信号写成编号，演员只接收编号，不在现场讨论颜色和曲目名称。
- 公核不得一边处理设备故障，一边维持角色。安全或设备出现问题时立即退出角色。

如果预算允许，技术场控和公核分开会更稳。五恋陪加一公核的演员配置仍然可以保留，技术位不参与演绎。

## 避免与《流氓叙事》重合的方法

### 更换故事的因果方式

《流氓叙事》大量依靠旧日秘密、身份遮蔽、长期误解、牺牲和事后重读。新本可以采用当下结盟、公开谈判、现场背叛和权力重新分配。

人物需要在彼此活着、能够争辩的时候完成选择。爱情证明可以是放权、作证、共同承担或允许对方离开，不以死亡作为统一答案。

### 避开辨识度过高的机关

- 不使用贫穷架空国、两族大屠杀和外来家族贩卖军火的组合。
- 不使用医院作为阴谋中心，也不把记者家族与国际资本再次放在同一结构里。
- 不使用催眠失忆、真假人格、同一身份由两人共同组成等核诡。
- 不把恋陪统一写成假装憎恨、默默牺牲和死后留信。
- 不复制火柴、镜子自爱、金色碎片、项链入海等视觉回收。

### 保留可以学习的结构能力

- 角色复杂度允许悬殊，分角时如实说明。
- 欢乐环节承担人物和伏笔任务。
- 恋陪进入公共事件，也与其他玩家产生关系。
- 公核给每个人不同身份，并用共同空间形成集体记忆。
- 后期真相重新解释早期动作，玩家仍有当场回应和选择的机会。

## 结构验收题

写完人物关系图后，逐项回答。

1. 拿掉某名恋陪，这名玩家会失去一项行动能力，还是只少几场情绪戏。
2. 拿掉公核，五名玩家的共同生活会不会立即失去具体形状。
3. 每场私聊是否改变了公共桌面的信息、权限或计划。
4. 五名玩家能否用五句明显不同的话描述自己的体验。
5. 每个重大秘密是否同时影响至少三个人。
6. 五名恋陪是否都在公共事件中做过与爱情无关的事。
7. 五个最终高光是否采用了不同动作。
8. C 位的痛是否来自玩家自己的选择，而非作者突然夺走爱人。
9. B 位是否拥有秘密的使用权，同时仍会被未知材料刺中。
10. A 位的爽感是否由真实权力产生，桌上其他人能否拒绝或反制。

其中三项答不上来时，先修关系结构，不进入人物正文。
