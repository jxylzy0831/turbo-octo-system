# 《末日学校》第一幕公共戏 v3 内部评估

评估对象：`drafts/末日学校-20260928-第一幕读本后公共戏-单房间开学典礼-v3.md`。本评估只判断文本设计，尚无真人试玩数据。

## 结论

v3 解决了单房间执行问题，没有解决“好玩”和“拉羁绊”的问题。不建议按三十至三十五分钟原样试演。

## 玩家在桌上实际会经历什么

- 四轮小课大多是按顺序展示人物能力。没轮到的玩家可以插话，但并无必须关注或影响下一轮的理由。一个人上场时，其他人容易等时间过去。
- 四轮结果太稳。广播必然调通，七号必然画光，陈渡必然画虚线。玩家的动作主要改变几句接话，不改变现场局面。
- 迟野被扣饭看似有代价，但稿里保证谷雨最后一定把牌放回。玩家可能察觉争论是在走流程。
- 最有可能引起笑声的是广播里锅盖掉落、迟野和谷雨顶嘴。它们足以支撑几分钟，撑不起整段公共幕。
- 玩家与对位 NPC 的独特关系只短暂露面。许照没有为了迟野真正承担或拒绝一件事；周砚没有机会让周晴用自己的本事帮到他；叶停只看见七号说“自己画”；闻笙只听陈渡解释实线和虚线。后续很难把这些当成共同经历反复回收。

## 下一版先满足的条件

1. 只设一个全场同看的麻烦，让四名玩家的行动互相影响，不再排四轮展示。
2. 开场两三分钟内给一个意外和一个笑点。笑点从人物做事失手、当众嘴硬或彼此护短产生。
3. 给每组一件可以当场选择做或不做的小动作。NPC 必须依玩家的选择改变下一步，而非只换一句台词。
4. 玩家做出的事留下可见痕迹，例如饭桌上谁的牌少了、谁替谁改了名字、录音保留了谁的一句话。后续幕再真实回收。
5. 先写十二至十五分钟的核心段，找四名目标玩家试玩。分别问他们最想继续和谁相处、记住了自己做过什么、哪一段只想快进。没有反应就改核心段，不先扩成三十五分钟。

一个可能的核心事件是谷雨第一天扣迟野的饭。迟野用玩笑试她底线，周晴当众拦，其他人决定帮谁、怎样重新分；与此同时收音机意外放出谷雨录广播时饭糊了的声音，让她的强硬与窘迫同时被看见。这个方案仍需检验；若现场只是吵规矩，说明事件仍不够好玩，需要再换。
