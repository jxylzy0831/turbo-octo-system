# 阿奇 A/B/C 本逻辑审计（2026-08-03）

## 审计口径

- A 本主审：`output/阿奇A本-v2-校订版.docx`。
- B/C 本主审：`output/阿奇B本.docx`、`output/阿奇C本.docx`。
- `output/阿奇A本.docx`、`output/阿奇A本-v2.docx` 为废弃文件，不纳入审计，也不据其提出任何结论。
- 对照：主持人手册、黛利拉 A/B/C 本、程聿怀 A/B/C 本、阿奇互动手册及工程已确认硬约束。
- 本轮只审查，不修改正文或原始资料。

## 总结

当前 A/B/C 不能直接作为最终一致版本交付。发现 1 项阻断级问题、5 项重大逻辑问题、3 项中等问题。

## 阻断级

### 1. 真阿奇死亡仍被放在第六幕

- B 本第五幕提示结束后，正文才进入海上坦白与死亡；随后明确写“第六幕小黑屋及此后现场出现的阿奇”是第二阿奇。
- 主持人规则明确：第五幕文本已经推进至 2005 年；真阿奇死于 2003 年；第五幕后出现的阿奇均为黛利拉幻想。
- 工程硬约束也明确要求删除“真阿奇之死放在第六幕”的结构。
- 当前结构会使演员在第五幕后仍以真阿奇理解现场，直接破坏真假阿奇边界。

## 重大逻辑问题

### 2. A/B 对阿奇战争责任直接自相矛盾

- A 本第四幕复习明确禁止补写阿奇“签字、调款、主动策划”。
- B 本海上坦白却写：“你签过字、调过钱，先救走程聿怀。”
- 这既是跨本冲突，也把主观罪责感写成未经来源支持的客观共谋行为。

### 3. 第二阿奇拥有黛利拉不可能提供的记忆

- C 本写第二阿奇记得“1980年的怒河、程亮冬的钢笔、1995年的帷帽、2000年的吻”。
- 第二阿奇只能拥有黛利拉知道、见过、听真阿奇讲过或想象出的内容。
- 黛利拉并不知道程亮冬与阿奇的钢笔细节，也不知道“延迟”内部形成过程的完整第一视角。
- 这里把真阿奇 A 本的全知资料直接复制给了第二阿奇。

### 4. 第二阿奇独立拜访心理医生，违反单一身体规则

- C 本先写阿奇“独自出门会失去记忆”，紧接着又写“你去找心理医生”，并与医生完整对话。
- 未交代黛利拉身体切换、诊疗记录、谁把身体带到诊室、黛利拉是否知情。
- 这与“现实只有一具身体”的规则正面冲突，且正是硬约束点名要求删除或重写的旧问题。

### 5. 粉黛珍珠来源被改写，削弱阿奇—程聿怀关系

- 原关系事实：阿奇向程聿怀提出盗窃比赛；程聿怀负责把守珍珠；阿奇获胜，程聿怀成全其“神偷”名声。
- A 校订版改为从一名普通收藏家保险室盗出珍珠。
- 这不仅换了事件来源，也删掉程聿怀对阿奇独立身份的理解与成全，使两人的关系从“君臣/战友/朋友”被压窄为事务搭档。

### 6. 2000 年船上相识被改成单向善后，破坏两人“平视”关系

- 黛利拉 A 本中，两人先相互挟持、拆招、试探，阿奇展示拟声与策略，最后以两个平视者互换姓名。
- A 校订版改成阿奇发现尸体后直接替黛利拉处理现场，冲突与反制基本消失。
- 结果是阿奇再次成为单向救助者，黛利拉从危险而平等的对手变成被善后的对象，与已梳理的爱情关系基础不一致。

## 中等问题

### 7. B 本死亡幻觉混入黛利拉的“姐姐妈妈”

- 真阿奇临死时写“姐姐妈妈在水里叫你的名字”。
- 摩伊拉是黛利拉的选择母亲，不是阿奇的原生亲属；两人也缺少足以支撑这种临终亲属召唤的直接关系。
- 该句容易被理解为旧版“阿奇也有姐姐妈妈”的残留，应删除或明确为阿奇想起黛利拉讲述的摩伊拉，而非自己的归家者。

### 8. 功能页仍保留临时发本逻辑

- B 本写“阅读至此，请暂停，等待主持人指示”“你可以在 B 本结束后阅读 C 本”“不可向尚未进入第七幕的玩家解释……”。
- 已确认的使用方式是 NPC 演员开本前完整阅读 A/B/C，各幕前只复习对应页。
- 这些句子会让演员误解阅读权限与发本节奏。

### 9. “真阿奇爱他，所以死去”压扁死亡动机

- 真阿奇的死亡同时来自：对 2000 年战争的罪责感、作为“延迟”的身份困境、对大义与爱情的撕裂、主动寻求解脱，以及对黛利拉的爱。
- C 本用“真阿奇爱他，所以死去”概括，会把复杂悲剧误读成单纯恋爱牺牲，也削弱阿奇—程聿怀—布雷族三方结构。

## 建议修复顺序

1. 重排 B 本，让 2003 年死亡在第五幕结束前完成或回溯完成；第五幕后全部切换第二阿奇。
2. 删除 B 本“签字、调款”等具体共谋行为，与 A 本统一为“身份责任与主观罪责”。
3. 重写 C 本心理医生段，显式交代同一身体、人格切换和黛利拉可知信息边界。
4. 恢复粉黛珍珠与船上初遇中阿奇—程聿怀、阿奇—黛利拉的关键关系事实。
5. 清理旧功能页指令、姐姐妈妈残留和过度简化的死亡总结。

## 当前判断

- A 校订版：主干基本可用，但两处关键关系事实偏离原作。
- B 本：需要结构性重写，不能只做局部润色。
- C 本：主题方向成立，但知情边界与单一身体规则需要重写关键段落。
