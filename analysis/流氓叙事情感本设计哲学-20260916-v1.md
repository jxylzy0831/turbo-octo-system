# 从流氓叙事理解情感本设计与新本写作

《流氓叙事》最值得学习的地方，是它让人物的生存方式、关系中的具体照顾和玩家当场的行动互相连接。玩家先拥有一段关系，随后发现自己对它理解得不够，最后需要带着新的理解回应对方。

我核对了主持人手册，并检索、对照了六位角色的十八册 A/B/C 本，重点读了人物动机、分幕任务和关键回收段落。以下涉及核心剧透。对效果的判断属于文本设计分析，实际体验还取决于玩家和主持执行，不能据此断言每一桌都会同样感动。

**先看它究竟让玩家在乎什么。**

手册的人物导言强调，理解这些角色，要考虑他们所处的环境和承受的压力。这个提醒很关键。极端行为只有接上人物一直以来的生存方式，玩家才有可能理解，进而愿意扮演。

蒋伯驾长期被当作可以消耗的工具。程走柳为他过生日的意义，接在这种经历后面，就远远超过一次恋爱示好。他第一次得到的东西很具体，有人关心今天是不是他的生日，关心他这个人过得怎么样。

程走柳同样习惯为了目标压下自己的感受。蒋伯驾后来反复回来，关心她被自己忽略的需要，两个人之间便有了相互辨认的基础。这里的相爱有原因，而且原因会继续影响他们怎样付出、怎样推开对方。

以撒与缪宏谟的关系则包含更尖锐的冲突。以撒起初希望把爱的人留在身边，缪宏谟最渴望的却是自由。手册把以撒看到她被戴上戒指时的痛苦，写成一个转变节点。他需要面对一个很难接受的事实，自己的某些爱法也会伤害她。

因此，新本的人设可以先写成一句能导致行动的话。例如一个人相信，只有持续有用，别人才不会抛弃自己。随后写清，这种信念曾怎样帮助他活下来，又让他怎样伤害了关系。爱情进入以后，对方必须做出一件足以挑战这种信念的事。

“缺爱”“隐忍”“疯批”这些词，可以用来快速介绍角色，却不足以决定一场戏该怎么写。

来源为主持人手册 P25至48、P72至104、P130至174，蒋伯驾 A 本 P209至238。本文段落编号按原 DOCX 正文非空段落抽取。

**关系要经过玩家的手。**

蒋伯驾和程走柳的老派约会被拆进前几幕。第一幕给约会卡，第二幕接上船票，第三幕配上馥芮白，到第六幕还有新的卡片和手链。读者知道他们想去约会，玩家则要把东西交给坐在面前的人。

这个区别会直接影响最后的告别。玩家可以记起自己送礼时的迟疑，也记得对方当时怎样回应。文本里的过去，和这一桌刚刚发生的事，开始共同支撑这段关系。

奥丁的处理也一样。手册要求他前期照顾所有玩家，给蒋伯驾解释的机会，接其他人的话。第三幕又通过歌词卡，让大家说出自己的经历。到第六幕，他会让众人把手搭在缪宏谟手上，也会带大家为以撒打光。

我的理解是，这些动作让“我们支持你”变成可以被当场感受到的回应。奥丁最后守门牺牲时，玩家此前已经与他共同度过了一段时间。

写新本时，每条重要关系都该有一件当场能完成的小事。它需要对方回应，也应该留下后续影响。可以是共同完成一项任务，也可以是替对方保守一个秘密。若一个环节结束以后，双方的认识和接下来的行为毫无变化，这段互动就还需要重写。

来源为主持人手册 P668、P677至685、P1101至1102、P1334至1349、P1855至1908，蒋伯驾 A 本 P706至712、P902至904。

**让玩家重新理解自己已经经历过的事情。**

火柴是很完整的例子。

前面的火柴环节有清楚的规则。点燃后提问，对方在燃烧期间回答，也可以吹灭火柴拒绝回答。它给玩家提供了开口的理由，同时把犹豫、拒绝和等待变成桌上可见的动作。

后面的羌青瓷演绎再次使用火柴，展开其试图遗忘程聿怀、最终又放下第三根火柴的过程。之前用来询问别人的东西，这一次显露了使用者自己的挣扎。玩家已经熟悉点火与熄灭的节奏，因而更容易注意到那根迟迟没有完成使命的火柴。

阿奇的秘密也会改变黛利拉对陪伴的理解。手册明确，真正的阿奇死于 2003 年，第五幕后出现的是黛利拉幻想中的阿奇，现场因此要求后续互动转入单独空间。这里的秘密连带约束了演员能在什么地方出现，其他人能否与他交流。

好的反转需要承担这样的工作。新信息出现以后，玩家能重新理解一个早已存在的动作，并因此改变对人的态度。单纯增加一个隐藏身份，往往只能提供短暂惊讶。

设计时可以倒着检查每次揭示。玩家此前具体相信什么，凭什么相信；现在凭哪一条证据改变看法；改变之后，他想对谁说些什么。如果最后只剩下对设定复杂程度的惊叹，情感上的作用就还不充分。

来源为主持人手册 P1201至1205、P403至405、P2153至2205，程聿怀 C 本 P516至525。

**公共事件要逼近每个人的私人关系。**

《流氓叙事》的战争、媒体操纵和家族利益，会进入角色的职业、家庭和爱情。缪宏谟想经营好医院，为母亲换得离开的机会；后来她面对的是自己参与建设的地方正在囚禁更多女性。蒋伯驾的受控燃烧计划，则把救更多人的意图与具体死伤放在一起，让他无法轻易为自己开脱。

这些内容使人物的痛苦有了不同来源。有人受害，有人参与了造成伤害的过程，还有人必须与自己在乎的人站到对立面。玩家即使同在一桌，也有不同的理由发言。

到了纪念典礼，角色共同揭露莱诺家族，并通过公开承认自身罪行，把对方的责任一并揭开。前面各自保守的事情，在这里变成共同反抗所付出的代价。之后再进入奥丁和各条关系的告别，集体行动已经先得到一次回应。

新本最好也有一件所有角色都必须参与的公共事件。检查它时，可以暂时拿掉所有爱情描写，看每个人是否仍有必须到场的理由。再把关系放回来，看某个人推进目标时，会不会真的影响另一个人珍惜的东西。

来源为缪宏谟 A 本 P740、P1581至1599，蒋伯驾 A 本 P1030至1052，主持人手册 P1947至1994。

**最后一幕需要回答人物一开始的问题。**

黛利拉结尾的镜子尤其明确。手册专门解释，这条线希望她学会自爱，并要求在阿奇退场后，让她看见写着 home 的镜子里的自己。这个舞台动作把结尾与她始终向外寻找爱的经历联系起来。

蒋伯驾与程走柳的老派约会也有相似的完整性。两人前面不断推迟的普通愿望，到了后面才显得格外珍贵。告别的力量有一部分来自玩家知道，他们曾经想过怎样一起生活。

但作者希望表达的道理，不会自动成为玩家接受的感受。黛利拉的现场演绎先提供左右手的选择，随后规定阿奇举起她的左手，完成接受治疗的结局。这里存在一个需要正视的设计取舍，作者保住了预定主题，却压缩了玩家对结局的决定权。这是同一套流程内部的取舍，不属于资料之间的事实冲突。

新本可以采用固定结局，但要明确玩家真正能决定的事情。告别时是否原谅、留下什么话、怎样理解这段关系，都可以产生差异。若向玩家承诺可以决定某人的去留，就应当兑现相应分支。身体互动也应留出无需强行拉扯的替代执行方式。

这里讨论的是作品中的虚构叙事和舞台效果，文中的疗法与人格设定不作为现实心理治疗依据。

来源为主持人手册 P123至129、P2256至2280，黛利拉 C 本 P640至675，蒋伯驾 C 本 P537至708。

**写一个新本，可以按下面的顺序推进。**

1. **先定义你想让玩家经历的变化。** 写下开场时玩家怎样看待自己，结束时希望他能怎样重新理解自己，再说明中间哪段关系促成了变化。避免把目标写成“全员哭”“极致虐恋”，这些无法指导具体场景。

2. **选一个能持续制造两难的公共事件。** 可以是必须完成的任务，或者一桩旧事终于要公开。为每个人写清必须参与的理由，以及参与会损失什么。事件要能连续产生行动，单有宏大的世界背景还不够。

3. **先写人物的因果，再写人物履历。** 过去的一件事让他学会某种生存办法；这个办法使他获得一些东西，也损害了某段关系；后来有人做了与他预期不同的事，他才开始动摇。把这条过程写通，再决定年龄、职业和修辞。

4. **让每个人同时进入公共行动和私人关系。** 除核心情感对象外，给他一个与其他玩家必须合作或交涉的理由。特别检查沉默的玩家能否被他人自然需要，避免所有重要关系都依赖主持人单独照顾。

5. **分开写真实时间线和玩家获知顺序。** 真实时间线记录谁做了什么、付出了什么。获知顺序记录每幕各人知道哪些事实，会据此作出什么合理判断。每个秘密都要有可信的隐瞒原因，揭示以后还要给玩家留出回应时间。

6. **先做能玩的场景骨架。** 每幕写清当前要办的事，以及玩家必须与谁互动。关系变化要落在动作里。完成这一步之后，再把角色本扩成完整的阅读文本。

7. **给重要动作安排后续回收。** 一件物品先有日常用途，后来参与关系，最后才承担告别。回收时最好增加新的意义，避免只是把同一句情话再说一遍。

8. **把主持人手册与角色本一起写。** 明确某段互动由谁开启，玩家不说话怎么办，提前猜中秘密怎么办。演员忙于一条关系时，其他人应该有可做的事情。把这些问题留到排练才处理，会迫使演员临场修补结构。

分幕可以先用下面这份工作表。它归纳了原作的节奏，也加入了适合新作检查的目标，不要求你的新本必须七幕。

| 阶段 | 玩家主要在做什么 | 写完以后要检查什么 |
|---|---|---|
| 初见 | 为眼前事件表态，认识同桌 | 玩家是否知道自己要办什么事 |
| 相处 | 开玩笑、试探，完成一次小合作 | 是否发生了足以在后面被记起的互动 |
| 靠近 | 分享过去，作出一点承诺 | 别人的回应是否影响了这个人 |
| 破裂 | 发现立场或利益冲突 | 冲突能否由已有事实推出 |
| 重识 | 获知秘密，重新评价关系 | 真相是否改变了下一步行动 |
| 行动前夜 | 解释误会，决定还要不要同行 | 玩家是否有自己的话可以说 |
| 共同结果与告别 | 完成公共行动，处理私人关系 | 前面的承诺与动作是否得到回应 |

**初稿完成后，要测试玩家究竟获得了什么。**

测本时记录每个人第一次主动关心别人发生在哪一幕。记录某段揭示以后，玩家想开口却被下一段演绎打断的地方。再观察谁长时间只在阅读或旁听，检查这段时间能否给他一个有后果的行动。

复盘可以问四个具体问题。

- 你最想留下哪个人，为什么是他？
- 哪一件事是你在这一桌亲手做过、现在还记得的？
- 哪次揭示改变了你对某个人的判断？
- 有没有一个时刻，你已经不认同角色，却只能继续照着做？

这些答案比哭泣次数更能帮助修改。若玩家记住的是演员一段很长的独白，却说不出两人之间发生过什么，下一轮就补相处。若玩家认同人物动机，却在高潮时无话可说，就检查他是否已经在前面把该说的话说尽，或者关键事实仍未交到他手里。

你现在最适合先完成的，是一份短的设计稿，包含六个人的核心矛盾、一件共同事件，以及逐幕的玩家行动表。读这份稿的人应当能看出来，某两个人为什么会在乎彼此，哪件事会让他们无法继续原样相处，最后各自还保有什么决定权。把这些写到具体，再开始长篇正文。
