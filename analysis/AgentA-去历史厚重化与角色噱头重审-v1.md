# Agent A 补充评审：去历史厚重化与角色噱头重审

## 一句结论

停卖历史。卖玩家身份。

《潮痕》和“墙倒之夜”都把最容易宣传的位置给了时代背景，把五名玩家藏在说明书里。商业入口应该反过来。玩家先看见“今晚我能做什么、别人为什么需要我、我的爱有多危险”，随后才愿意进入世界。

## 一、为什么《潮痕》和“墙倒之夜”都不适合作为商业爆款入口

### 1. 海报上的主角是事件，不是玩家

《潮痕》最醒目的词是停火协议、自治议会、警务重组、失踪者调查庭、秘密武装和联邦安全处。“墙倒之夜”最醒目的词大概率会是边境、开放、东西阵营、通行与历史拐点。

这些词都在告诉玩家“你要来理解一个时代”，没有先告诉玩家“你会成为一个多爽、多狠、多痛的人”。用户买剧本杀，不是报名参加历史研讨会。

背景承担得太多，角色欲望承担得太少。

### 2. 角色盲选无法在十秒内完成

《潮痕》的五席要靠职业和制度解释才能成立。

- 首席谈判代表为什么有多大权力，需要解释三方协议。
- 档案联络员为什么掌握全员秘密，需要解释磁带与线人体系。
- 急救署署长为什么能决定两处救援，需要解释城市指挥系统。
- 社区医生为什么能拉回全场，需要解释她与家属网络。
- 码头电工为什么是唯一破局者，需要解释旧线路与封锁区。

解释越多，盲选越弱。盲选卡应该让玩家立即投射自己，而不是先理解机构图。

### 3. 五席的职业气质过于接近

五人都是三十岁上下、严肃、负责、背负公共使命的专业人士。她们的道德重量不同，第一眼的幻想却相似。海报并排时，玩家看到的是五位“有责任的体制或民间精英”，看不到五种完全不同的戏剧快感。

角色差异要先发生在欲望和权力上，职业只是实现手段。

### 4. 历史厚重感会抬高审美门槛，也会限制情绪尺度

一旦作品借重大真实历史做显性入口，玩家会自然要求它对制度、立场、受害者和现实创伤负责。恋爱情节稍微浓一点，会被质疑消费历史。恋爱稍微轻一点，五恋陪配置又失去价值。

这是一组结构性冲突。不是文笔能解决的。

### 5. 两个方向在产品感受上其实相同

《潮痕》是停火前夜。“墙倒之夜”是开放前夜。二者都包含历史转折、旧友重逢、边界变化、秘密档案、公共选择和时代洪流。

换了地名与史实，没有换玩家第一小时的体感。玩家仍然要先读背景、认阵营、理解旧账，再等待自己进入命运。

这不是第二个产品，只是同一产品的另一张历史皮肤。

### 6. “爱会不会剥夺选择”还是论文题目

这个命题适合做创作发动机，不适合直接做营销口号。它没有人物、动作和危险。

玩家真正愿意传播的说法应该是下面这些。

- 他替我选了一条人人羡慕的人生，今晚我把它退回去了。
- 我只要越过她的意愿，就能救更多人。
- 所有人都以为我被爱得最好，只有我知道自己从没选过。

同一个命题，必须变成人物的具体困境。

## 二、从海报、角色盲选和口碑反推五席噱头

先冻结五句产品承诺。人物姓名、职业和世界观都可以后改，这五句不能动。

| 席位 | 海报第一眼 | 盲选时玩家想要什么 | 玩家离场后的口碑句 |
|---|---|---|---|
| A 权力位 | 全城的结果，必须等她点头 | 我要当真正能谈、能压价、能拒绝的人 | “最后所有人都在等我开条件，那一刻真的是我说了算。” |
| B 把柄位 | 她握着每个人最怕公开的原始证据 | 我要知道得最多，还能拿秘密换东西 | “我不是吃瓜，我决定谁先塌房，也决定替谁把秘密留下。” |
| C 高痛位 | 她救过所有人，代价是亲手牺牲最爱她的人 | 我要有能力、有责任，最后被自己的选择刺穿 | “没人能说我当年做错了，可我还是失去了最想留下的人。” |
| D 关系位 | 每个人最狼狈的时候都找过她，仍有人在人群里只选她 | 我要全场有关系、有人回头、有人公开偏爱 | “他们吵到谁都不信的时候，只有我能把人叫回来。” |
| E 翻盘位 | 人人都认定她是罪人，最后只有她能救场 | 我要前期受压，后期用别人不会的本事完成翻盘 | “他们审了我半场，最后全场只能把钥匙交给我。” |

这五句具备三个共同条件。

1. 都有独占动词。点头、公开、牺牲、召回、破局。
2. 都包含别人对玩家的依赖。
3. 都能在不解释世界观的情况下成立。

角色盲选卡控制在三行以内。

- 第一行写别人怎样看她。
- 第二行写她独占什么。
- 第三行写她最怕爱人知道什么。

不要先写履历。履历不卖票。

## 三、什么事件既有大压力，又没有历史教材感

需要的不是重大历史事件。需要一个“所有人都能在十五秒内理解的制度切换夜”。

它有五个条件。

### 1. 影响的是日常权利

姓名、婚姻、工作、医疗、居住、隐私、信用、出境、被遗忘的权利。这些东西不需要历史知识，玩家马上知道失去它意味着什么。

### 2. 零点后不可逆

数据库锁定、直播永久存档、名单生效、城市系统上线、旧身份销毁。不可逆性比战争规模更重要。它迫使玩家当场选择。

### 3. 五人恰好各握一个必要权限

压力不能只来自新闻播报。A 能批准，B 能披露，C 能调度，D 能召集见证人，E 能进入或关闭系统。拿掉任何一席，结果都会改变。

### 4. 公共事件直接侵入五段爱情

制度不只影响“人民”，必须影响恋人的姓名、证词、身体安全、公开身份或共同生活。公共与私人使用同一个选择，不另开两条线。

### 5. 背景说明不超过三百字

如果三百字讲不清，事件过重。玩家不是靠理解历史获得沉浸，而是靠看见自己的人生即将被锁死获得沉浸。

适合的事件类型包括：全国身份库迁移、全城人生分配系统上线、国民真人秀最后直播、特赦名单锁定、隐私档案公开表决、撤离资格永久生效。

不要再用真实国家、真实阵营和真实历史节点。它们不是压力的必要原料。

## 四、三个高概念故事发动机

## 方案一：《退回你的人生》

### 一句海报文案

零点，“最优人生系统”将替全城做最后一次选择。五个被它选成样板的人，今晚决定让它上线，还是把自己的人生退回去。

### 发动机

一座近未来城市把工作、居住、医疗优先级和伴侣匹配交给“最优人生系统”。五名玩家是第一批样板用户，也是系统成功的公众证明。零点，强制版将覆盖全城。上线前，一份原始训练档案证明，五人的“幸福人生”都经过爱人或监护人的人工干预。

这不是 AI 技术故事。系统只做一件事，把“我替你选是为了你好”制度化。

### 五席噱头简表

| 席位 | 一句话噱头 | 现场独占动作 |
|---|---|---|
| A | 她是全城最成功的人生样板，只有她的确认能让系统覆盖所有人 | 批准、延迟或拆分上线，并公开向城市提条件 |
| B | 她握着五个人被删除的原始愿望，知道每段完美人生改过几次 | 公开、交换、归还或永久删除五份原始档案 |
| C | 她设计过一次救下全城的最优解，也亲手删掉爱人拒绝她的权利 | 在新危机中决定是否再次越权调用系统替人选择 |
| D | 她是系统匹配率最低的人，却被四名玩家和爱人一次次主动选择 | 召回被系统排除的证人，决定谁能进入最终公证 |
| E | 系统把她判定为高危废人，今夜只有她能物理切断主机 | 进入核心机房，在数据、证词与自己身份之间完成取舍 |

### 五名恋陪的产品手感

- A 恋陪是共同设计规则的人。他能托举 A，也最有能力制造一份没有她同意的完美方案。
- B 恋陪曾替她改过一项原始愿望。他既是线人，也是第一份必须由她决定是否归还的秘密。
- C 恋陪是那次最优解的直接承受者。他承认她救了人，但拒绝让统计数据替自己同意。
- D 恋陪是全城唯一公开拒绝系统匹配、仍然选择她的人。
- E 恋陪拥有进入机房的路线，却不能替她拔掉电源。

### 公共 NPC 噱头

他是“最优人生系统”的创始人，也是五名样板用户共同的人生规划师。全城把他叫作最懂幸福的人。五个人今晚会发现，自己最重要的选择几乎都由他提前改过。

他不必是邪恶科学家。他真的爱五个人，也真的让他们过得更安全。问题恰好因此成立。

### 最大风险

最大风险是写成廉价 AI 寓言。角色一旦开始解释算法、公平率和技术伦理，人物就死了。

控制办法只有一个。所有系统功能必须落到熟悉的人生问题。你住哪里，你和谁结婚，你能不能见到病中的亲人，你的拒绝是否会被保存。技术名词控制在五个以内。

## 方案二：《今夜以后，没人叫这个名字》

### 一句海报文案

零点，旧身份库将永久销毁。五个活在别人名字里的人，必须决定谁有资格做回自己。

### 发动机

多年前一次全国性数据灾难让大量人失去合法身份。一套临时“新名计划”给无证者重新分配姓名、履历和家庭关系。今晚新身份将永久生效，旧库随后销毁。五名玩家既是计划的受益人，也是当年身份置换的知情者。

一份错误匹配清单出现。有人借新身份逃过罪责，也有人为了保护爱人，擅自替对方选择了姓名、家庭和去处。

### 五席噱头简表

| 席位 | 一句话噱头 | 现场独占动作 |
|---|---|---|
| A | 她现在的名字属于国家英雄，只有她能签下旧库销毁令 | 决定永久生效、延期核验或公开听证 |
| B | 她记得五个人真正叫什么，也握着每个名字背后的罪与恩 | 交换、归还、公开或埋葬真实身份 |
| C | 她当年把上千人送进新身份，也亲手把爱人登记成“已死亡” | 决定现时错误名单先救谁，并承担旧日登记后果 |
| D | 五名玩家中有四个人的“新家人”由她亲自找到 | 召回真实家属、新家属与见证人，决定谁有资格认领谁 |
| E | 她在法律上已经死了，却是唯一能进入旧库的人 | 潜入档案核心，选择带回原名、罪证或他人的合法身份 |

### 公共 NPC 噱头

他是当年给五个人起新名字的登记官。无数人把他视为救命恩人。他知道每个名字为何被改，也把“让你活下去”当成替人决定一生的许可证。

### 最大风险

最大风险是身份诡计化。玩家会把注意力放在“谁是谁”，人物关系会退化成解谜。它也更接近《流氓叙事》中身份遮蔽、旧秘密和事后重读的感受。

若采用，必须在第一幕就公开所有人的当前身份，谜面只允许是“谁替谁作了决定”，不能是“谁其实不是谁”。

## 方案三：《最后一场全民直播》

### 一句海报文案

五个被全国爱了十二年的人，今晚第一次决定，摄像机还配不配继续拍他们的人生。

### 发动机

五名玩家从少年时期起参加一档长达十二年的国民真人秀。节目记录她们的成长、爱情、争吵与公益行动，也塑造了整整一代人对“理想人生”的想象。最终季直播前，一段未剪辑母带证明，节目组曾操控她们的分手、疾病公开、事业选择和一次重大公益救援。

今晚直播无法取消。五人可以照原脚本完成国民告别，也可以夺回频道，当着全国观众公开自己如何被爱、被保护、被安排。

### 五席噱头简表

| 席位 | 一句话噱头 | 现场独占动作 |
|---|---|---|
| A | 她是十二年收视女王，只有她拥有直播切断键 | 控制直播、改脚本、逼赞助方和平台当场让步 |
| B | 她曾是最不起眼的幕后剪辑者，手里却有所有人的未剪母带 | 决定哪段人生按原样播出，哪段永远留在镜头外 |
| C | 她用一次直播决定救下十万人，也擅自公开了爱人最不愿示人的秘密 | 在新的公共危机中选择救援效率还是爱人的明确拒绝 |
| D | 她是全网最想保护的国民妹妹，也是其他四人关机后第一个找的人 | 把决裂的成员叫回镜头，决定谁能拥有最后一次真实发言 |
| E | 她被剪成了全国最恨的反派，只有她知道隐藏导播间怎么进 | 劫持频道、恢复原始画面并决定是否为自己翻案 |

### 公共 NPC 噱头

他是十二年总导演，也是镜头外真正照顾过五个人的人。观众认为他创造了她们，五个人一度也这样认为。今晚他第一次无法剪掉她们对他的回答。

### 最大风险

最大风险是显得轻浮，或者落入《楚门的世界》式熟悉感。公共 stakes 如果只剩塌房与热搜，就支撑不起 C 的痛和全场羁绊。

解决方向是把节目与一项真实公共资源绑定，例如长期公益基金、未成年人影像权诉讼或数百万用户的私密数据。仍然不要写行业报告，公共后果只保留一条。

## 五、明确推荐

选《退回你的人生》。

它是三个方案里产品闭环最强的。

### 1. 海报能卖

“你以为自己过得很好，后来发现连幸福都是别人替你选的。”这句话不需要历史知识，也不需要科幻爱好。每个人都理解。

### 2. 五席容易做出完全不同的盲选

A 是系统样板和最终批准者。B 握原始愿望。C 是最优解的设计者与执行者。D 是被主动选择的关系例外。E 是被系统放弃、却能物理断电的人。

五个人不再只是五位严肃专业人士。她们有五种明显的第一眼幻想。

### 3. 主题天然进入机制

替爱人决定可以提高效率、降低风险、保住系统或救下更多人。尊重选择会带来时间、公共利益或安全代价。命题终于不是靠台词宣布。

### 4. 场控可以成为世界的一部分

灯光、广播、权限提示、档案解锁都可以由系统界面合理触发。音画不是装饰，是城市在替人安排生活的在场证据。

但技术场控仍应独立于公共 NPC 的表演峰值。世界观可以整合，岗位不能混成一个人。

### 5. 与《流氓叙事》距离最大

它不依赖真实大屠杀、边境冲突、战争阵营、身份替身、医院阴谋或死后遗书。主要动作发生在当下。五人是从一套仍在运转的生活系统里夺回权限。

## 六、让 Agent B 重写前必须冻结的产品约束

这些是需求，不是建议。每条都要附上提出者。提出者是 Agent A，目标是保证产品入口和现场可玩性。B 可以调整人物表达，不能静默删除产品功能。

### 约束 1：不再使用重大真实历史事件做显性基底

可以借制度压力，不出现真实国家、真实阵营、真实历史日期和需要玩家预习的政治背景。世界说明正文不超过三百字，口头能在二十秒讲清。

### 约束 2：冻结一句总海报文案

暂定为：

> 零点，“最优人生系统”将替全城做最后一次选择。五个被它选成样板的人，今晚决定让它上线，还是把自己的人生退回去。

B 可以润色字句，不能把购买理由重新改成时代背景。

### 约束 3：冻结五席的第一人称口碑承诺

- A：全场必须等我点头，我能真实改变规则。
- B：我握着每个人的原始秘密，也能决定秘密的用途。
- C：我的决定救过很多人，也亲手伤害了最爱我的人。
- D：我进入所有人的关系，并在最失势的时候被公开选择。
- E：所有人先把我当废人或罪人，最后只有我能完成破局。

任何人物设定若不能加强对应承诺，删除。

### 约束 4：五张盲选卡不得使用世界观术语解释爽点

每张三行以内。必须包含一个独占权力、一个外界标签和一个爱情危险。不能用系统部门、政策名称或历史履历填充。

### 约束 5：每席只有一个不可替代的终局动作

A 批准，B 发布，C 调度，D 召回，E 切断。动作可以影响彼此，不能由另一席代办，也不能全部集中到 A 最后总结。

### 约束 6：每席在前九十分钟内兑现一次小高光

不允许玩家等到终局才发现自己很重要。

- A 先赢一次小谈判。
- B 先用一份秘密换来权限。
- C 先做一次有限资源分配。
- D 先叫回一个拒绝合作的人。
- E 先修复或突破一处系统。

### 约束 7：主题必须有对价

五对关系各出现一次代决选择。替爱人决定能获得明确公共收益，还权会支付明确成本。没有对价的“尊重选择”不算机制。

### 约束 8：五名恋陪保留五种主手感

托举、试探、追责、偏爱、并肩继续保留，但不是五个人轮流讲边界。每名恋陪至少影响另一名玩家一次，且在公场完成一次与爱情无关的动作。

### 约束 9：公共 NPC 不死亡，不洗白，也不全知

他必须真的改善过五人的人生，也真的篡改过五人的选择。他后期失去授权，仍留在现场承担关系后果。不能靠死亡结束审判，不能用“都是为了你们好”自动获得原谅。

### 约束 10：技术场控与公核的峰值职责分离

最好使用独立技术场控。若人数锁死，公核只在固定退场窗口操作预排队列，关键表演段由恋陪单键触发。设备故障优先退出演绎，不让公核一边挨五个人追责一边找音乐。

### 约束 11：私聊总数先封顶八场

A、B、C 可各两场，D、E 各一场作为原型。之后只有试演证明某段关系缺失，才能加回。每场必须改变公场信息、权限、计划或关系状态。

### 约束 12：公共结局只保留三条状态轴

- 系统状态：强制上线、限制上线、关闭。
- 真相状态：谁的原始愿望先公开，谁获得删除权。
- 人物状态：五人是否保留样板身份并承担旧日责任。

不要制造几十种排列组合。玩家感到选择有效，比结局数量重要。

### 约束 13：不存在完成任务即可无代价全赢

战术可以全胜，价值必须有代价。全城效率、个人选择权、五人免责三项最多保住两项。

### 约束 14：技术词汇不超过五个

不要解释模型训练、算法参数、数据架构和系统治理。玩家只需要理解五件事：它替谁选择、谁能修改、谁能看到原始愿望、谁能关闭、零点后什么不可逆。

### 约束 15：先写宣传页，再写故事大纲

B 的下一份交付不应直接是七幕大纲。先交付一页产品定义。

- 总海报文案。
- 五张三行盲选卡。
- 五名玩家各一个可现场执行的高光动作。
- 五对爱情各一次有收益的代决选择。
- 公共 NPC 一句宣传噱头。
- 三个不可兼得的终局结果。

这页过关，再写大纲。
