# 阿奇 A/B/C 本 v2 重写硬约束

## 来源边界

1. 主持人手册与阿奇互动手册决定事件事实、出场顺序和真假阿奇边界。
2. 黛利拉、程聿怀等角色本仅补充其人物已知视角，不得反向赋予阿奇未经手册确认的行动。
3. 不再补写阿奇具体原生亲人。她的童年以布雷族共同处境、教育与大义形成过程为核心。
4. 2000年战争只使用手册表述：程聿怀或“延迟”因某种原因与莱诺家族挑起战争并在最后放弃布雷族。不得写阿奇签署计划、调拨战争资金或预知屠杀结果。

## 感情线

1. 1995年：阿奇救下少年黛利拉并已心动，但尚未把感情命名为爱情。
2. 2000年：以真实身份重逢，阿奇才确认自己爱他。
3. 阿奇主动制造浪漫、送礼、照顾；男黛利拉主动亲吻、占有、要求阿奇留下。
4. 男黛利拉为清瘦、漂亮、情绪外露的“小型猛兽型杀手”，不得写成冷硬寡言的传统男性杀手。

## 第二阿奇

1. 只拥有黛利拉知道、看见、听阿奇讲过或自行想象出的阿奇记忆。
2. 不知道程亮冬、延迟内部事务、阿奇独自准备绝笔等黛利拉未知事实。
3. 采用黛利拉主观幻觉中的双人叙事；舞台上可以拥抱、牵手、同船，但正文必须埋下现实只有一具身体的破绽：旁人不回应、礼物来源断片、镜像只出现黛利拉、动作与时间无法同时成立。
4. 第五幕后出现的NPC阿奇全部为第二阿奇；真阿奇死于2003年。
5. 第二阿奇不以“保护机制”自我定义。她可以知道自身来源，但其主体性来自2003—2005年间自行形成的欲望、恐惧、嫉妒、爱与选择。

## 分幕与功能页

1. A本对应第一至第四幕；B本对应第五、六幕；C本对应第七幕及尾声，具体信息释放必须再按角色本与互动手册校准。
2. 第五幕必须完成或回溯真阿奇2003年死亡，并跨至2005年；第五幕后所有现场阿奇均为第二阿奇。
3. 演员开本前完整阅读A/B/C。每幕功能页写成“该幕演出前复习”，不写“停止阅读”“不得提前翻页”。
4. 保留“你需要做到”、可公开/须隐藏信息和动作提示，但不得创造改变玩家流程的新任务。
5. 演员伴手礼为剧情外附页，不计入尾声，也不承担设定揭露。

## v1必须删除或重写

- 阿奇童年中的“姐姐妈妈”。
- “阿奇签过战争计划、亲自调款”等未经来源确认的共谋细节。
- 第二阿奇掌握程亮冬、延迟内部和真阿奇绝笔准备等不可能记忆。
- 第二阿奇独立拜访心理医生而未交代身体转换的场面。
- 真阿奇之死放在第六幕的结构。
- 面向玩家临时发本的“暂停翻页、不可提前读下一本”指令。
- 把主观双人幻觉当成客观两具身体、又突然切换为同一身体的叙事混乱。
