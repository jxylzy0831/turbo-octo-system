# 流氓叙事十二层创作逆向报告

《流氓叙事》的现有材料已经能支持你提出的十二个分析方向。其中，互动触发、NPC 表演、信息控制和道具前后呼应，能够还原到具体动作。亲密感是否建立、某个反转是否令人难过，则仍需现场材料验证。

目前最明确的创作规律，是把角色过去的亲密经历写进玩家本，再让玩家在现场参与对应的动作，最后改变这些动作与物品的含义。阿奇线的绷带与手心记号、蒋程线的约会路线、缪以线的三枚戒指，都采用了这种安排。

这份报告覆盖十二个层面，重点精读阿奇全部已提供互动，以及羌青瓷和奥丁承担的关键流程，并与玩家本中的任务、回忆和结尾交叉核对。十八份玩家本完成了原件文本与幕次核对；此轮没有逐句评注五十九万字符，也没有逐张核验文档内图片。它可以作为一部作品的创作方法案例，尚不足以证明跨作品通用规律。

## 材料范围与结论等级

目录内共有十八份玩家本，六名角色各有 A、B、C 本，另有组织者手册和阿奇互动手册。二十份摘录与当前原件逐段一致，合计 590269 个字符。这个数字包括重复段落、扫描水印和其他文字噪声，不能直接视为有效创作字数。

正文采用三类结论。

| 标记 | 能说明什么 | 不能替它说明什么 |
| --- | --- | --- |
| 文本明确证实 | 资料写出的情节、动作、流程及作者明确说明的意图 | 玩家实际产生了同样的感受 |
| 根据设计推断 | 从安排与后果之间推导出的功能、取舍和创作规则 | 作者真实的写作顺序或完整心路 |
| 需要实测验证 | 关于参与感、亲密感、情绪强度及改造效果的假设 | 已经得到验证的结论 |

手册明确将羌青瓷和阿奇列为恋陪位。四对爱情关系中，两对由玩家彼此扮演，两对由玩家与 NPC 扮演，奥丁承担亲情、友情和群像连接。三名核心 NPC 之外，流程另有幕后声与客串角色需求。借鉴到四组恋陪时，需要重新安排演员职责与公共互动。〔证据02、03、04、05、40、41〕

## 一 故事架构

**文本明确证实。** 世界的主要冲突围绕布雷诺的族群仇恨，以及莱诺家族与缪家对战争的利用展开。新闻、电台、医院和军火交易进入同一条因果链，几名角色以各自职业和身份参与其中。人物的私人损失，又成为他们复仇和合作的原因。〔证据02、03、04、23、25、50〕

故事时间与游戏呈现顺序需要分别整理。

| 故事时间 | 关键事件 | 对关系的影响 |
| --- | --- | --- |
| 1990年 | 程聿怀与瑞法在大学相识相爱 | 为结尾恋爱真相提供过去 |
| 1994年 | 程家父母之死与家庭变故 | 兄妹各自走上追求真相的道路 |
| 1995年 | 程聿怀调查后被洗去记忆，成为延迟；阿奇加入延迟这一身份 | 恋爱记忆被切断，替身秘密开始成立 |
| 2000年 | 金狮医院开业，众人相遇，后发生大屠杀 | 爱情和群像关系进入共同灾难 |
| 屠杀后至2005年 | 怒河复仇，人物身份与立场发生变化 | 私仇、亏欠与合作条件交织 |
| 2003年 | 真阿奇死亡 | 此后的阿奇出现需要采用黛利拉的主观视角 |
| 2005年 | 仓库对质、合谋、纪念典礼揭露、主要告别 | 前期秘密逐层兑现 |
| 后续人生与尾声 | 各人的实际结局，缪宏谟晚年的讲述与想象结局 | 回看整个故事，并完成谢幕 |

表中年节点由小传与关键玩家文本互证，仍是主线年表，没有扩写成所有人的逐年履历。〔证据03、04、05、24、29、44、47、49〕

游戏从通缉令与认罪开场，再回到2000年的医院。玩家接下来的阅读不断补充过去，也推进现实事件。开场的认罪词先提出问题，后期的公开认罪再改变其含义。作者后记明确指出，最终证词中仍有不准确的部分，它们混在大量真实内容之中，构成主角反击莱诺家族的叙述手段。分析时必须保留这层复杂性。〔证据07、29、43〕

**根据设计推断。** 四条爱情线能够共处，是因为新闻操纵与战争给所有人的个人故事带来后果。主线事件一旦发生，就同时改变多条关系。可迁移的检查办法，是逐件询问公共事件改变了谁的处境，并确认后续有人必须采取行动。

## 二 人物设计

**文本明确证实。** 手册专门区分了角色复杂度与适配玩家。程聿怀的信息量、事业线和理解成本较高；黛利拉对爱与情绪的关注更集中。作者并未将角色统一成同一种恋爱需求。〔证据02〕

| 人物 | 文本中的主要需求 | 需求带来的行为与冲突 |
| --- | --- | --- |
| 程聿怀 | 追求真相与个人理想，保护被划入自己一方的人 | 倾向控制局面，也会屏蔽行动造成的个人伤痛 |
| 程走柳 | 还父亲清白，坚持新闻理想 | 压低自己的感受，推开会干扰判断的爱情 |
| 蒋伯驾 | 在长期被当作工具后，学习作为一个人生活 | 重视他人，却常独自承担责任和代价 |
| 缪宏谟 | 让母亲与自己获得自由，延续救人的信念 | 善于伪装和反击，也会陷入职业罪责 |
| 以撒 | 获得爱、承认与安全感 | 早期占有欲与缪的自由需求冲突，后期需要改变自己的爱法 |
| 黛利拉 | 保住爱与家庭，缓解被抛弃的不安 | 对爱给予极大回报，也会抗拒失去 |
| 羌青瓷 | 保护程聿怀，推动对家族的反击 | 隐瞒过去、接受仇恨，公开态度与私下目的分离 |
| 阿奇 | 在使命之外拥有自己的生活与爱 | 无法持续陪伴，承担愧疚，常以礼物和笑容回应黛利拉 |
| 奥丁 | 守护由失去家庭的人组成的家 | 接话、照顾各人，也要承担群体行动的损失 |

这些需求直接来自人物介绍与小传。对现场玩家来说，它们仍是需要理解和接手的角色条件。〔证据02、03、04、05〕

**根据设计推断。** 人物的吸引力可以从需求落实到行为。阿奇的温柔有很具体的方式，记得承诺、把普通照顾做成专属礼物、回应黛利拉荒唐的话题。羌青瓷的复杂则体现为对不同对象保留不同信息，演员不能仅用统一的温柔语气替代这种差异。〔证据09、11、16、24、46〕

这里加速亲密的起点，是让现实中陌生的玩家与演员接手已经相爱的角色。第一幕阿奇私聊被手册定义为文本初见后的重逢。后续的关系推进因此借用了角色已有的亲密历史。设计新作品时，要明确玩家现场是在初识、重逢，还是挽回关系。〔证据09、45〕

## 三 关系网络

**文本明确证实。** 关系之间存在可追踪的行动后果。

| 关系 | 怎样进入现场或影响后续 |
| --- | --- |
| 程聿怀与程走柳的兄妹关系 | 走柳调查兄长变化，私下获知羌青瓷计划，并承担保密任务 |
| 蒋伯驾与缪宏谟的兄妹关系 | 共享家庭经历；第六幕缪参与分担蒋的压力 |
| 程走柳与缪宏谟的友情及合谋 | 千纸鹤、共同反击与怒河创立，让关系持续产生动作 |
| 程聿怀与阿奇共同构成延迟 | 身份秘密直接影响黛利拉的杀人任务与结尾真相 |
| 缪、走柳与以撒妹妹之死 | 职业行为造成的伤害，必须在第五幕对质中解释 |
| 蒋伯驾与黛利拉母亲之死 | 受控燃烧计划的代价被受害者当面追问 |
| 奥丁与六名玩家 | 家人、朋友、同行者等不同关系，在前期互动及遗物分配中逐人呈现 |

〔证据04、15、20、22、24、25、27、31、47〕

**根据设计推断。** 群像成立至少需要两种联系。一种给玩家共同做事的理由，例如保护医院后一起给奥丁选唱片。另一种让一个人的选择对别人造成后果，例如第五幕的责任对质。只在背景里写“你们是好友”，仍缺少现场关系发展的过程。〔证据21、25〕

奥丁还承担一项很具体的公共功能。他可以把私人表达交给其他人回应。第六幕中，几名玩家把手搭到缪的手上，其他人又为以撒打光。这些动作让一对关系的情感场景需要全桌参与。是否让旁观者真正投入，仍需观察。〔证据28〕

## 四 情感结构

各条关系使用的递进方式并不相同。

| 关系 | 早期建立的东西 | 中后期怎样改变它 |
| --- | --- | --- |
| 阿奇与黛利拉 | 礼物、专属称呼、出现的承诺，以及被接纳的日常 | 揭示真阿奇的死亡，重释2003年后的陪伴，最后将 home 指向镜中的自己 |
| 羌青瓷与程聿怀 | 利益婚姻、共同演恩爱、试探与调情 | 先揭示洗去记忆，再揭示保护与过去的爱情，让早期言语获得新的含义 |
| 蒋伯驾与程走柳 | 曾经错过的约会，通过食物、船票和咖啡分次补足 | 把约会路线对应到行刑路线，换血小剧场再揭示隐瞒的照顾 |
| 以撒与缪宏谟 | 渴望爱与渴望自由之间的冲突，以戒指反复呈现 | 揭示以撒逐渐改变决定，最终通过摘戒指演出放弃束缚 |

表内事件与动作属于文本证实；它们在玩家心中形成何种情感递进，属于设计推断。〔证据09至13、16、33、35至41、44〕

**根据设计推断。** 阿奇线既有可体验的甜蜜，也反复让陪伴受到使命限制。手册与玩家本将礼物放在这种缺席和歉意之中。后续揭示会让玩家重新考虑，先前接受礼物时，阿奇承受着什么。单独增加礼物数量，未必能保留这种作用。〔证据05、46〕

**需要实测验证。** 三条告别关系都涉及隐瞒、牺牲或单方面替对方作决定。不同玩家可能感到深情，也可能感到被排除在重要决定之外。评估时需要分别记录对牺牲的理解、对人物的感情和对决定方式的接受程度。

## 五 互动机制与对话欲生成

**文本明确证实。** 对话通常有角色内的发起理由，并附带可执行任务。

| 场景 | 发起理由 | 玩家可以做的事 | 交流的推进条件 |
| --- | --- | --- | --- |
| 阿奇首次私聊 | 本中留言邀请重逢 | 画戒指、切牌喊停、同步翻牌 | 礼物与共同动作完成后返回阅读 |
| 羌程首次私聊 | 需要统一对外的恩爱说辞 | 补充故事、接住试探、选择怎样一起返回 | 建立公开相处的口径 |
| 第一幕心理测试 | 游戏失败后回答同一问题 | 写答案，解释双方差异 | 由差异进入个人线索分享 |
| 第二幕火柴提问 | 各人带着疑问前来 | 问指定对象、续燃、拒答 | 火柴规则限定一段回答 |
| 第三幕唱片店 | 给奥丁买礼物需要用故事交换 | 选歌词卡、讲相关经历 | 各人的故事换得唱片 |
| 第五幕仓库 | 身份揭示与受害者追责 | 指认、解释、回应责任冲突 | 奥丁救场后转入合作动员 |
| 第六幕誓师 | 行动前最后一次充分交流 | 回应具体关系与未说完的话 | 转入共同的最终行动 |

〔证据09、10、14、17、19、25、26、27、35〕

**根据设计推断。** 一段对话要继续，双方至少需要有未完成的事情。它可能是共同完成一项动作，也可能是解释一个对方无法接受的选择。羌程私聊尤其适合研究，双方需要让外人相信他们恩爱，又在私下互相试探，同一句话可以同时服务公开关系和私人目的。〔证据14、15〕

这些机制能提供话题、提问理由和下一步动作。手册仍大量依赖 NPC 起哄、提问和代说，不能据此断言玩家会持续主动交流。开场还要求玩家阅读时暂不沟通，等任务出现再说话。因此，这部作品能提供的是分阶段的对话生成办法，现场连续性仍由阅读、私聊与公共流程共同决定。〔证据07、08、17、25〕

迁移时可以使用一个最小检查。删掉情话以后，两人是否还有眼前必须处理的事；交流结束以后，信息、行动或关系是否发生了变化。两个问题都答不出来的场景，很容易需要演员硬找话题。

## 六 情绪调度

**文本明确证实。** 手册给出了逐阶段的气氛要求和转场动作。

| 阶段 | 手册安排的主要变化 | 承担的任务 |
| --- | --- | --- |
| 开场 | 通缉令、火光、认罪 | 先让玩家接触将来需要理解的行为 |
| 第一幕 | 欢乐、冲突平息、配对游戏 | 认识人物，建立公共相处方式 |
| 第二幕 | 八卦与火柴提问 | 加深关系差异，安排专属照顾 |
| 第三幕 | 讲述过去，奥丁带着失落出现 | 让各人获得理解，开始改变气氛 |
| 第四幕 | 灾难后陈述、羌青瓷转为敌对 | 让创伤获得对象，形成复仇方向 |
| 第五幕 | 绑架、责任揭示、对质、救场 | 私仇充分暴露后，建立合作需求 |
| 第六幕 | 回应各人、共同支撑、告别约定 | 在决战前再次确认彼此关系 |
| 第七幕 | 公开证据、认罪与反击 | 让玩家共同完成主线行动 |
| 无声之旅 | 奥丁死亡与遗物交接 | 回收前期习惯，并让玩家作出悼念回应 |
| 无所容心 | 羌青瓷等待赴死的揭示 | 为过去言行的重释做准备 |
| 第十幕 | 四对关系分别完成揭示和演绎 | 兑现此前的物品、动作与秘密 |
| 尾声 | 想象结局及演员说出自己的名字 | 补充告别，完成故事与演出的结束 |

〔证据07至08、17至19、23至33、40至42〕

**根据设计推断。** 第三幕奥丁的失落，发生在前两幕话唠、搞笑的状态之后；第六幕又安排笑话与日常约定。玩家有机会先记住一个人的相处方式，再遇到这种方式无法继续的时刻。最后一分钟、最后的魔术和遗物，由此拥有明确的前文。〔证据04、20、27、30、31〕

当前能够绘制的是文本预期的情绪顺序。资料没有给出每阶段实际耗时、玩家情绪评分或冷场记录，不宜画成有精确强度数值的效果曲线。

## 七 伏笔与反转及信息分配

**文本明确证实。** 最关键的信息存在不同的知情时间。

| 信息 | 提前知情者或执行者 | 延迟揭示的方式 |
| --- | --- | --- |
| 阿奇与延迟的关系 | 程聿怀及演员掌握核心秘密 | 玩家任务要求保密；第五幕手册要求截住提前说出阿奇身份的行为 |
| 羌青瓷的保护计划 | 羌青瓷与第五幕私聊后的程走柳 | 走柳受托保守过去相爱的秘密，并在公开场合扮演对立 |
| 2003年后阿奇的存在方式 | 演员按真假规则呈现 | 第五幕后仅在小黑屋出现，直到结尾解释黛利拉的主观经历 |
| 老派约会的最后意义 | 蒋伯驾的安排逐渐显现 | 早期赠礼对应路线，后期信件把它对应到行刑过程 |

〔证据05、24、25、39、44、47〕

**根据设计推断。** 反转有两类材料相互支撑。一类改变事实解释，例如照片是谁拍的、2000年的初见是否确为初见。另一类改变情感解释，例如同一张约会卡后来代表什么。后者需要玩家记得以前发生过的事，才能发生回看。〔证据33、39、44〕

阿奇小黑屋的空间要求还参与了事实控制。它让其他人无法在2003年后的时间里直接与阿奇共同互动。若为增加群像感，让假阿奇回到公共场合与其他角色说话，就会改变这一叙事前提。〔证据05、12〕

仍有需要检验的公平性问题。第五幕靠任务与主持拦截维持秘密；玩家若提前猜出真相，演员的固定揭示能否接住这种反应，现有资料未给出完整方案。不能把手册要求隐瞒的信息，自动判断为自然且稳定的悬念。

## 八 沉浸机制

**文本明确证实。** 多件道具有清楚的使用动作，并在后期再次出现。

| 物品或动作 | 前期用途 | 后期用途 |
| --- | --- | --- |
| 黛利拉左手绷带、阿奇右手 home | 现场照顾与玩家亲自留下的记号 | 终幕左右手选项，再由镜中的 home 转向黛利拉自己 |
| 糖果罐 | 两人共同整理、带走礼物 | 复盘将糖解释为治疗药丸的暗示 |
| 戒指与红桃A | 魔术中的礼物与关系确认 | 支持神偷先生、魔术师和专属关系的持续识别 |
| 黄油多士、船票、馥芮白 | 分次补足老派约会 | 约会路线在信中对应最后的行刑路线 |
| 三枚戒指 | 以撒与缪之间的关系承诺 | 摘戒指体现放弃束缚；尾声想象结局又重新佩戴 |
| 奥丁耳机、笑话本、便利贴 | 音乐习惯与分别照顾各人的方式 | 死亡演绎、遗物交接和玩家悼词 |
| 千纸鹤 | 缪与走柳之间具体的回应 | 缪在走柳墓前再次赠予 |

〔证据09、11、12、13、20、22、31、35至39、41、42、49〕

**根据设计推断。** 值得复用的是道具的使用过程。谁递出，谁留下记号，谁在结尾再次碰到它，都需要安排清楚。只有“这个物品象征爱”的说明，尚缺玩家与它共同经历的那部分。

音乐同样受到具体约束。奥丁生平中的歌与流程使用的歌不同，手册要求现场采用适配文本与流程的《Don't Cry》。雨声是阅读转场提示，黑灯与帘幕用于切换演绎和叙述状态。它们既承担气氛，也帮助玩家理解现在应该阅读、回应还是观看。〔证据04、07、30、31〕

作品对催眠、药物和精神状态的描述，在本报告中仅作为虚构叙事设定使用。不同段落采用的医学名称并不一致，不能据此提炼现实治疗办法。〔证据05、12、13、44〕

## 九 NPC表演系统与主动行为

**文本明确证实。** NPC 的行为受到场景、对象和秘密共同限制。

| NPC与阶段 | 需要执行的目标 | 明确的表演要求或限制 |
| --- | --- | --- |
| 阿奇第一幕私聊 | 完成重逢与共同动作 | 让玩家画图、喊停、翻牌，适时送玩家回去阅读 |
| 阿奇一二幕公共场合 | 陪伴黛利拉，也参与全桌气氛 | 接其他 NPC 的话，带黛利拉听别人的故事，避免过度私聊 |
| 阿奇第五幕后 | 按主观视角呈现陪伴 | 只在小黑屋互动，不能被其他玩家当作仍活着的人对话 |
| 羌青瓷早期 | 主持公共关系，维持夫妻口径 | 对所有人接话，私下与程聿怀试探 |
| 羌青瓷第四五幕 | 制造对立，促使责任与隔阂被说出 | 保持优雅和克制，对不同对象使用不同信息 |
| 羌青瓷终幕 | 揭示过去的爱与赴死选择 | 恢复温柔与遗憾，回收火柴和名字的含义 |
| 奥丁前期 | 破冰、接话、照顾全桌 | 平息过度对立，给蒋解释的机会 |
| 奥丁第六幕 | 让每人获得具体回应 | 黛利拉提出未预设的问题时认真倾听，目光与回应不敷衍 |

〔证据03、05、08、09、24、25、28、33〕

已有少量明确分支。黛利拉没有介绍爱人关系时，阿奇补充；仓库中玩家没有说明事实时，羌青瓷代说；程聿怀在吐真剂私聊中追问爱情时，羌青瓷假装清醒并打断；奥丁则承认第六幕无法预设所有问题，给出回应的重心。〔证据10、16、25、28〕

**根据设计推断。** 可以据此建立一个有限的行为状态表，记录当前时间、公开身份、掌握的秘密、对话目标、允许泄露的信息和退出条件。它已经比单写“阳光温柔”更可执行，但现有手册还没有覆盖玩家沉默、持续拒绝、跳出任务和提前破解时的全部反应。

阿奇终幕尤其需要区分宣布的选择与实际流程。手册先说明左右手对应两种决定，随后要求阿奇将伞交到左手，举起玩家左手，推进接受治疗的固定结局；对挣脱也有继续举手的指令。这是固定收束中的选择呈现，资料未给出完整的两条结果分支。〔证据13〕

若借鉴这一场，可以保留镜子与自爱主题，同时重新设计动作接受方式。具体方案列在验证文档中，属于本轮提出的改造，不能当作原作已经提供的互动边界。

## 十 流程控制

**文本明确证实。** 主持工作有明确的分工与资源调度。

羌青瓷作为主 D，需要与六人互动，不能持续只与自己的 CP 说话；奥丁需要为最后面向全桌的情感场景提前建立关系；阿奇也需要带黛利拉听其他人的故事。第二幕的阿奇出场时点，可以根据演员是否空闲调配，但仍须放在指定关系分享之后。〔证据08、18〕

第一幕游戏上场顺序不确定，三名 NPC 根据现场分担提问。读本中途的私聊、电话、领取物品和回座继续阅读，都有文本与手册互相提醒。第五幕则安排了玩家未回应时的代说，第六幕结束提醒玩家处理离席需求，再进入后续沉浸段落。〔证据07、10、16、25、27、35至38〕

**根据设计推断。** 流程能持续推进，依赖明确的触发与补位。设计新场景时，应同时写出正常入口和遗漏后的入口，例如玩家忘记出门，谁提醒；玩家没有说出关键事实，谁接住；公共话题结束，演员用什么动作转场。

这里也有取舍。代说能减少卡顿，却可能让玩家逐渐变成听众。评估需要记录每次关键交流由谁发起，以及演员代替玩家完成了多少任务。手册标称6.5小时，只能作为作者给出的总时长，不能据此推导每名玩家持续被关注的分钟数。〔证据01、25〕

## 十一 玩家心理与投入机制

下列机制均为**根据设计推断**。它们有对应文本安排，实际心理效果尚未得到证明。

| 设计安排 | 可能促成的体验 | 可以观察的现场证据 |
| --- | --- | --- |
| 已有恋爱历史接现场共同动作 | 玩家较快接手亲密角色关系 | 能否用自己的话回忆初次私聊的具体动作 |
| 对个人需求给予专属回应 | 感到角色记得自己、理解自己 | 是否主动向 NPC 提出新需求，回应是否接住它 |
| 礼物、称呼与约会分次出现 | 形成下一次互动的预期 | 是否主动提起尚未完成的约定 |
| 在全桌面前确认关系 | 感到关系在共同世界中成立 | 是否与其他人讨论自己的关系，而非只找 CP |
| 延迟揭示过去的代价 | 重新理解早期相处 | 能否指出哪段过去改变了含义 |
| 共同支撑与遗物交接 | 感到自己参与了群体关系 | 非 CP 之间是否出现主动回应与后续提及 |
| 镜子上的 home | 将告别与自我关系联系起来 | 是否能说明镜中自己为何与前期记号有关 |

〔证据09至14、19至22、28、31、35至39、44〕

哭泣不能单独区分对人物的投入、对演员的感受、音乐影响或对自身经历的联想。要判断玩家在乎的是否为这个角色，可以在复盘中让其描述最想再问角色的问题，以及自己记得的共同经历。再结合现场是否主动接话和行动，结论会更具体。

“删掉动作会怎样”也需要实测。比如保留同样的戒指与台词，删去画图、切牌与同步翻牌，预期可能降低共同参与的感觉；也可能对喜欢直接观看演绎的玩家影响很小。两种结果都要允许出现。

## 十二 创作方法论

**作者明确说明的部分。** 黛利拉的设计初心是学习自爱，镜子的摆放不可省略。作者后记也解释了作品题名与藏真隐实的叙述方式。这两项可以直接归入作品明确的主题目标。〔证据06、13、43〕

**根据设计推断的部分。** 从成品可以整理出一套供新作品使用的工作顺序。

1. 为每名角色确定具体需求，并写出它如何影响行动。
2. 将 CP 需求放在一起，找到能互相给予的部分和无法直接调和的冲突。
3. 为每次见面提供角色内的理由，安排双方实际可以做的事。
4. 分配各人知道的信息，写明公开说法与私下目标。
5. 用少量物品、称呼或习惯连接多次相处，并让含义逐次变化。
6. 让公共事件对私人关系造成后果，给其他玩家参与和回应的机会。
7. 安排揭示顺序，让后期信息能改变对早期经历的理解。
8. 同步写玩家任务和主持触发，补上沉默、拒绝与提前知情时的处理。
9. 逐角色检查参与机会，再用反事实改动测试关键设计是否有作用。

这个顺序是本轮构建的创作流程，无法据此判断作者当年按同样顺序写作。
