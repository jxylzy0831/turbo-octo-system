# 流氓叙事写作风格分析

这套分析供《春日》的写作与改稿参考，重点是角色本如何组织人物欲望、亲密关系与叙述声音。最突出的特点是有立场的第二人称旁白、会自我辩解的人物心理，以及白话玩笑和浓烈抒情之间的转换。

## 资料和方法

复用项目现有的20份完整资料，其中18份为六名玩家的A、B、C本，两份为主持与互动手册。叙事统计只使用玩家本，手册用于核对作品意图和文本通向现场的方式。writing-dna-skill的文章语料流程在这里按角色本适配，不把两份手册当成同体裁文章。

20份源文件哈希与现有索引一致。来源和册次等元数据覆盖全部资料，见[语料元数据](语料元数据.json)。日期未核实，不拿文件修改时间当出版时间。本次分析作品级的合成风格，不外推任何一位署名作者的全部创作。

18份玩家本的清理后近似统计覆盖394493汉字，源文件的扫描识别噪声、印刷断行和少量角色内引导会影响数字。统计方法及词性限制见语言DNA，原始结果见[语言统计](语言统计.json)。

人工精读覆盖全部18份角色册，记录24个窗口，窗口内汉字累计约3.22万，包含部分前后语境。其余全文经过程序扫描，未声称人工逐字通读。六份Word的全部内嵌图像已查看取样索引，含对白图片另行放大核读。

## 原文复用

完整提取文本仍在 `分析/流氓叙事文本研究/提取文本/`，本目录不再复制一套完整语料。原Word段号与物理行号的对应关系保存在[精读窗口](精读窗口.json)。P段号不是页码，不能拿它当文件的物理行号。

从项目根目录读取选定原文，可以运行下面的命令。读取模式只显示原文，不生成统计或改动文件。

```powershell
python 自动化脚本/分析流氓叙事写作DNA-20261029.py --读选段 E02 E07 E08 E09 E16
```

## 使用范围

本次生成风格分析与后续写作参考，未改四位玩家本，未修改现有技能。没有开展匿名读者比较，也不据词频、检查通过或内部自评宣称达到某个复刻比例。

学习重点是人物如何为欲望寻找说辞、如何被对方改变，以及细节怎样在不同处境中产生新意思。原作的特殊案件、家族设定、医疗说法与道德立场不作为《春日》的设定来源。
