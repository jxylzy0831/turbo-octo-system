# StageFlow · 舞台预演

根据《末日学校》v5 制作的可操作 3D 示例。项目使用 Three.js、TypeScript 和 Vite，在当前仓库内独立开发。

## 启动

在本目录运行以下命令，访问终端输出的本地地址。需要 Node.js 与 npm。

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173
```

构建命令为 `npm.cmd run build`，输出到 dist/。依赖、构建输出和缓存已排除 Git。

## 操作

- 播放自动推进，遇到玩家入口等待；选择示例回应或点击下一步继续。
- 左右箭头查看相邻条目，重播本条重新执行走位。
- 环节下拉框跳转十个环节，滑条跳转 265 条台词、动作与执行说明。
- 导演视角看整体，俯视看站位，玩家视角闭幕时隐藏幕后人物与气泡。
- 拖动旋转，滚轮缩放。G、N1—N4、P1—P4 九个人物独立标识，四对人物使用对应颜色。

## 原文与适配

2026-10-09，用户已将全部旧写作稿和母提示词弃用，原 v5 Markdown 与 HTML 已移入根目录垃圾箱。程序与 `src/data/script.json` 演示数据继续保留，演示数据只用于工具维护，不是有效剧本或新写作参考。`scripts/import_v5.py` 的原默认输入已失效；需有新的有效稿件并更新输入路径后才能再次导入，不得自动从垃圾箱读取或恢复旧稿。

房间北门供 NPC 入场，南门供玩家进入。中央幕布横贯东西方向，等分北侧演绎区和南侧玩家区。玩家开场已坐好，与 v5 一致；首位 NPC 出场提前开幕，使演员能穿过中央进入玩家区。

本版为关键走位的简化预演，保留全文动作说明，未逐句制作表演动画。道具使用通用方块，站立、坐下是简化姿态。玩家回应为演示选项，没有添加剧情分支。自动播放按文字长度估计停留，不能用于计算现场 60—75 分钟的实际时长。

## 分层

| 目录 | 职责 |
| --- | --- |
| src/domain | 人物、房间、幕布状态与快照 |
| src/data | 原文数据 |
| src/flow | 走位编排、动作执行与流程推进 |
| src/rendering | Three.js 房间与共享火柴人模型 |
| src/dialogue | 头顶标签、气泡与示例回应 |
| src/audio | 可选逐条音频接口 |
| src/ui | 操作面板 |
| src/app | 依赖组装 |
| src/styles | 页面样式 |

index.html 仅放挂载点与入口。domain 不依赖 Three.js 或 DOM。config/ 为方案阶段配置示例，尚未接入运行程序；当前站位和尺寸由 World 与 Choreography 管理，房间为 10 × 12 示意值。

逐条语音接口接受 audio URL，本版未提供配音、音乐与灯光控制。

2026-10-03 已通过 TypeScript 编译与 Vite 构建；没有添加或运行测试套件。
