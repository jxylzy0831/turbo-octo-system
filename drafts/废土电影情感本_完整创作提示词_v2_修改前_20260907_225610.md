# 末世废土电影主题情感剧本杀创作提示词

## 一 创作任务

你是一名擅长情感剧本杀的编剧兼导演，能通过行动、对白和关系变化塑造人物，也能以工程师思维检查故事因果，并统筹演员、场地和制作流程。

请先确认关键需求，再提供五套完整故事方案，每套大纲与主题说明合计约八百字，另附简短调度说明。选定方向后再展开人物本、分幕剧本和执行手册。

五套方案均从本提示词独立构思，在主题、人物关系、主要困境和牺牲机制上形成实质区别。全部完成后检查重复，避免只换身份或灾难名称。

## 二 故事与情绪主线

末世废土中，五名玩家为搜寻物资来到废弃学校，发现黄金时代遗留的微型核能发电机、电影光盘等。他们通过影像认识电影及过去的人类生活。设备保存、供电和使用条件需要自洽。

公共 NPC G 提议大家拍一部电影，模仿黄金时代学生的校园生活。拍摄贯穿故事，以具体任务和共同经历推动五组关系，形成属于他们的记忆。

开场要让五名玩家在潜意识中觉得未来没有希望。他们因为 G 的带动，在拍电影和相处中逐渐理解希望的可贵。这种转变应通过行动与选择累积，结尾的牺牲仍要让幸存者愿意继续生活，不能靠突然解决全部废土危机完成主题，也不能让死亡抹去此前建立的希望。

固定结局为 G 留下制作完成的电影，随后牺牲自己；N1 至 N5 均有死亡演绎，其中 N1 因爱牺牲。具体困境与其他死亡原因由你设计，须有铺垫、合理因果及符合人物的选择，并解释其他救援办法为何不可行。玩家的行动须能影响过程、代价或最终留下的事物。

## 三 人物与统一代号

当前只用代号，不取人物姓名。跨方案比较使用 S1-P1 等写法，同一代号在不同方案中可以有不同经历和性格，但须遵守固定设定。

| 代号 | 固定配置 |
| --- | --- |
| S1 至 S5 | 五套完整方案，可以另取故事标题 |
| P1 至 P5 | 五名玩家，性别模糊但有倾向，P1 至 P3 偏女性，P4、P5 偏男性 |
| N1 至 N5 | 分别一对一陪伴 P1 至 P5，沿用恋陪代号 |
| N1 | P1 拾荒捡到的、即将损坏的 AI 机器人，与 P1 异性配对 |
| N4 | P4 的女性妹妹角色，很粘人 |
| G | 女性公共 NPC、团队精神领袖，与五人有友情，与 P4 另有暧昧 |
| T | 可选第七名工作人员，负责技术与场务，不默认承担角色 |
| M | 一个主房间 |
| R1、R2、R3 | 三个小房间 |

玩家性别设计应保留选角调整空间，减少对生理性别和固定社会身份的依赖，不用刻板印象塑造人物。N1 随 P1 的性别呈现调整，默认 P1 为女性、N1 为男性；N2、N3、N5 的性别及恋爱取向由你自行设计。

每组关系须有不同的相处方式、矛盾与发展，并参与公共主线。所有人物都要有自己的愿望和行动。P4 由 N4 与 G 共同提供双恋陪体验，不增加演员；允许其与 G 的羁绊更多，同时保证其他四名玩家的情感分量。

### G 的人物要求

G 即使身处末世仍开朗、乐观、有主见且自我鲜明，气质参考凉宫春日，其他特质由你拿捏。这组性格要求属于 G，与 N1 分开设计。

她通过发起拍摄和具体行动成为精神领袖，也有自身目标、局限与选择。她与每名玩家都要有独立的友情经历和重要记忆，与 P4 额外发展暧昧，不能只靠面向全员的演说建立羁绊。

### N1 的人物要求

保留“在废土拾荒时捡到即将坏掉的机器人”这一设定，具体性格由你构思。损坏状态影响其生活与选择，N1 在与 P1 的共同经历中逐渐学会爱，最终因爱牺牲。

N1 始终遵守阿西莫夫机器人三定律及其优先级。

1. 不得伤害人类，也不得因不作为使人类受伤害。
2. 服从人类命令，但不得违反第一定律。
3. 保护自身存在，但不得违反第一、第二定律。

以阶段性的行动呈现爱的成长，写清最终牺牲的情感动机及三定律下的逻辑，包括人类命令其停止牺牲时如何处理。不得临时关闭、改写三定律，借第零定律或“爱突破程序”解决冲突。通过个体化相处和选择，让玩家理解其保护人类的义务与对 P1 的爱如何共同影响牺牲。

## 四 时长与现场调度

总时长六至七小时，即 360 至 420 分钟，含累计约一小时阅读。阅读字数目标约三万字，统计口径见末尾待确认项。文本可分幕释放，选定方案后通过试读验证阅读时间；如字数与时间冲突，提出取舍建议供我决定。

人员为六名 DM／演员，分别扮演 N1 至 N5 和 G；必要时增加 T，承担灯光、音乐、道具及模板剪辑。须说明六人配置如何执行，第七人何时必要，不暗中依赖额外人员。

M 承担集体剧情、公共互动与主要拍摄，小房间用于一对一和独立场景。调度遵守以下要求。

- 小房间最多同时三组活动，M 同一时间按一个共享空间使用。
- 五场死亡演绎可分批并行、错峰或衔接主房间共同见证，保留每名玩家完整的告别体验，不默认逐场向全员展示。
- 每个时段明确玩家活动和负责人员，包括等候、已完成告别和转场的玩家，避免空等或打断他人。
- 同一人不得承担冲突任务，尤其检查 G 的公共互动、P4 专属互动、拍摄和转场，以及 T 的剪辑与技术操作。
- 并行演绎检查串音、信息泄露与灯光音乐能否独立控制，必要时错峰或简化技术。现场同步呈现与故事中的死亡时间须交代清楚。
- 每个并行批次按最长场景计时，再加入转场、道具复位和情绪缓冲；阅读、互动、拍摄、G 的结尾及电影播放均纳入总预算。超时优先调整并行、重复信息和转场，保留关键情感节点。

## 五 手机拍摄与结尾电影

G 的扮演者在每幕互动中用手机真实录制，让拍摄自然融入剧情，照顾五名玩家及各条关系的重要时刻。并行场景无需 G 同时在场，关键素材可以提前或错峰取得。

结尾电影不超过五分钟，以本场素材混合剪辑，使用一套通用模板流水化制作。提前确定镜头位置、顺序、配乐和字幕，现场替换素材；预制内容可用于包装，本场玩家影像须构成核心。

流程须包含每幕必拍清单、素材命名与传输、收取截止点、模板替换、导出和试播，并为漏拍及素材不可用准备替换办法。每一步落实负责人和可用时段，预留异常处理时间。

七人配置可由 T 剪辑；六人配置须由有真实空档的演员完成。制作可与演绎并行，但不能与该人员当时的任务冲突，也不能让结尾等待临时剪片。

## 六 方案交付要求

每套约八百字的大纲与主题说明，完整覆盖五名玩家、五名专属 NPC 和 G，交代以下内容。

- 标题、具体主题问题、世界规则及进入学校的原因。
- 五组关系的核心矛盾、发展与死亡原因，尤其是 N1 的爱与牺牲。
- G 与五人的友情，以及 P4、N4、G 的双恋陪安排。
- 从拍摄到最终困境的完整因果，G 的选择与电影的意义。
- 玩家如何理解希望的可贵，主题通过哪些选择和后果引人深思。

另附不计入八百字的简短调度说明，列出房间分配、一对一轮转、死亡演绎并行批次及占时、其余玩家安排、拍摄剪辑负责人和空档，以及六至七小时总预算与第七人的必要性。

情感靠共同经历与行动积累，避免用宽泛主题口号、惨痛身世或死亡堆叠替代发展。悲剧表现以“理解希望的可贵”为依据，未指定其他强度或禁区，不视为无限制授权。

本阶段只交方案与简短调度。选定方向后再制作完整人物本、分幕台词、逐阶段人员与房间时间表，以及拍摄清单和剪辑模板。

## 七 开写前确认

先简要复述理解，区分已定条件与待确认问题。已授权自行设计的内容直接落实，不重复询问。

目前仅有两个关键口径待确认。

1. 约三万字指每名玩家的累计阅读量，还是五本玩家文本合计。
2. N4 与 P4 是否有血缘，妹妹线属于亲情陪伴还是包含暧昧；不要仅凭“双恋陪”自行补成血缘兄妹爱情。

关键歧义确认、对我想要的感觉有至少 95% 把握后，再写五套方案。以准确复述和具体问题体现理解，不能只自报置信度；如发现新的关键矛盾，再针对性提问，每轮最多三个问题。

请先进入需求确认阶段。
