# 末世废土青春 MV 主题情感剧本杀创作提示词 v3

## 一 当前任务

你是一名擅长情感剧本杀的编剧兼导演。请独立构思一套故事，只提供主线分幕大纲，按“序幕、第一幕、第二幕……终幕”讲清整场发生什么、玩家做什么以及剧情怎样推进。幕数由故事需要决定。

本阶段不写人物本、详细恋爱支线、分幕台词、执行手册、逐分钟调度表或剪辑教程，也不提供多套备选。无新的关键歧义就直接出大纲，不重复确认已定条件。

## 二 故事与结局

末世废土中，五名玩家与同伴为搜寻物资来到废弃学校，发现黄金时代遗留的微型核能发电机、电影光盘等，通过影像认识过去的校园生活。设备保存、供电、播放与手机充电条件须自洽。

G 提议模仿学生生活、拍一部属于大家的校园影像。玩家起初觉得未来没有希望，在共同活动与相处中，逐渐有了想继续过的生活。G 有自身愿望和局限，通过具体行动带动大家。

固定结局为 G 留下制作完成的 MV 后牺牲，N1 至 N5 均有死亡演绎，其中 N1 因爱牺牲。死亡须有铺垫与合理因果，大纲简要交代其他救援方式为何不可行。玩家的公共选择可以影响过程、代价和留下的事物。最终仍让幸存者愿意生活，不靠解决全部废土危机或否定共同经历来收尾。

## 三 主流程要有青春洋溢的互动

主流程的青春气息参考 NewJeans《Ditto》MV 中朋友一起玩闹、相处、面对摄影机时自然放松的感觉。每个常规剧情幕都要安排具体的集体互动，让五名玩家亲自参与并形成共同记忆。

可设计笨拙学跳一小段舞、课间传纸条、给彼此画画像、临时组成乐队、玩简单球类、争抢合照位置，或把镜头后的 G 拉进画面。这些只是气质示例，请根据故事重新设计，不要逐项照抄，不要求玩家会跳舞或擅长表演。

活动应有当幕的起因、过程和结果，带来公共信息、共同决定或团队关系的变化。让玩家从生疏到熟悉，留下笑场、小默契和愿意再次参加的快乐。避免连续安排维修、分粮、查线索，把青春感全部留给后期滤镜。

校园生活由废土人物通过旧影像学习、误解和重新创造。互动应适合现有室内空间，不依赖额外的操场、屋顶或室外场地。最终危机与告别阶段承接前面的共同记忆，无须强塞欢乐游戏。

## 四 人物与恋爱线边界

只用以下代号，不取人物姓名。

| 代号 | 固定设定 |
| --- | --- |
| P1 至 P5 | 五名玩家，P1 至 P3 偏女性，P4、P5 偏男性，保留性别调整空间 |
| N1 至 N5 | 分别陪伴对应的 P1 至 P5，各有独立愿望与不同的相处方式 |
| N1 | P1 拾荒捡到的濒坏 AI 机器人，与 P1 异性配对，默认男性 |
| N4 | 与 P4 无直接血缘关系的成年女性妹妹，兄控、粘人、吃醋，对哥哥有占有欲，带暧昧依恋 |
| G | 女性公共 NPC，开朗乐观、有主见、自我鲜明，气质参考凉宫春日；与五人分别建立友情，与 P4 另有暧昧 |

N2、N3、N5 的性别与取向自行设计。P4 保留 N4 与 G 的双恋陪体验，同时照顾其他玩家的情感分量。

**每组 P/N 的恋爱情节独立于主线因果，G/P4 的暧昧也遵守这一要求。**

- 主线由全体面对的处境、G 发起的活动和玩家的公共行动推进。NPC 可以凭自身身份与能力参与公共任务。
- 恋爱进度、告白、吃醋、和好或拒绝亲密均不能改变主线推进、关键线索取得、资源解锁及公共结局。关键行动不能要求玩家先完成恋爱互动。
- 移除所有私人恋爱情节，公共故事仍须因果完整、可以跑通。主流程中的集体青春互动也不依赖情侣配合。
- 恋爱线只改变私人关系体验、相处细节和告别表达。本阶段最多点到各组支线的预留位置，不展开恋爱故事。

N1 在相处中逐渐学会爱，最终牺牲保留其对 P1 的情感动机，但不取决于 P1 是否回应爱情。它始终遵守三定律及优先级，即不得伤害人类或因不作为使人类受伤害；在此前提下服从人类命令；再保护自身。大纲须说明牺牲为什么符合这些约束，以及停止牺牲的命令如何处理。不得关闭程序、借第零定律或“爱突破程序”解决冲突。

## 五 最终 MV 与落地边界

最终成片不超过五分钟，参考《Ditto》的手持、低清 DV、自然光观感与轻微失焦，像被重新翻出来的私人录像。画面主体是本场真实发生的青春日常，保留少量笑声、呼唤和 G 的画外音，不用死亡集锦或大段遗言替代记忆。

G 的演员用手机在主流程中顺序拍摄，也通过固定机位等方式进入部分画面。各幕自然留下可用素材，不强迫玩家摆拍或产生指定反应。主素材在集中告别前收齐，用通用模板完成现场剪辑；参考《Ditto》不等于必须使用原曲。

整场 360 至 420 分钟。后续人物本目标为每名玩家累计约三万字、总阅读约六十分钟，需试读验证，本次不写正文。六名演员分别扮演 N1 至 N5 和 G，可增加技术人员 T；场地为一个主房间 M、三个小房间 R1 至 R3。

大纲保证粗略可执行即可。主房间同一时间作为共享空间，小房间最多同时三组；死亡演绎可错峰或并行，保留各自完整告别并照顾其余玩家。六人版剪辑须由确有连续空档的演员承担，或明确为何需要 T，不能让结尾等待临时剪片。

## 六 输出格式

先用一小段说明故事前提、核心困境与主题，然后依次写序幕、各幕和终幕。每幕只需讲清以下内容，采用简洁连贯的叙述。

1. 主流程发生什么，怎样承接上一幕并带向下一幕。
2. 玩家与 G 具体做什么，有什么青春互动，以及产生什么公共结果。
3. 留下哪一两个 MV 画面，玩家当时是什么感受，结尾再看为何有意义。

危机与终幕交代 N1 至 N5 的死亡安排、G 留下 MV 后牺牲的因果，以及幸存者最后做的事。最后用一小段估计各幕时长与总时长，说明告别和剪辑如何容纳在人员、房间限制内即可。

交付前检查主线能否在完全不展开恋爱支线的情况下成立，以及每幕互动是否真的让玩家共同经历青春日常。只输出这一套大纲，不附完整执行方案。
