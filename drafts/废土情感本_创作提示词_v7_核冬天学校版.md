# 末世情感剧本杀创作提示词 v7

请构思一套核冬天背景下、人类濒临灭绝的情感剧本杀。配置固定为四名玩家 P1 至 P4、四名一对一恋陪 NPC N1 至 N4，以及一名公共主持兼公共 NPC G，共四玩家、五名工作人员。以 NPC 的人设、欲望与选择推动剧情，用 EDD 校准玩家体验。

本任务不需要使用 human-writing 技能，也不套用该技能的语言禁令与审稿流程。语言风格由人物性格、场景和剧本表达需要决定。

## 世界与相遇

长期严寒、日照不足和食物匮乏已经改变人的生活，幸存者很难再遇见陌生人。灾难成因简要交代，生存条件前后一致。

四对人物循着无线电信号来到信号起源地的一所学校，在这里遇见 G。交代广播说了什么，各人为何前来，以及他们为何愿意留下。学校是共同生活的主要场所，寻找同类的愿望与电波联络持续影响后续行动。

情绪参考 NewJeans《Ditto》MV 中自然亲近的青春相处，以及重看旧影像时快乐与怅然交织的感受。校内空间与旧物应参与人物生活，让大家真正过上几段愿意再过一次的日子。核冬天的限制要影响选择，也给玩闹、拍摄和无用的小愿望留出时间。

## 四名恋陪

以下四席为本轮原创候选。默认 P1 至 P3 为女性，P4 为男性，N1 至 N3 为男性，N4 为女性，保留调整性别与取向的空间。人物只用代号。

- N1 是 P1 拾荒时捡回的、临近报废的教学辅助 AI。它笨拙直白，逐渐在相处中学会爱，想让学校再开一堂课，请大家教自己课本之外的事。它隐瞒记忆损坏，反复请求 P1 重教曾经学过的内容。始终遵守三定律及其优先级，不伤害人类或因不作为使人受伤害；在此基础上服从命令；在不违反前两条时保护自身。损坏、修复与归宿须有一致规则。
- N2 是 P2 的年上前任，当年由 N2 主动提出分手。他惯于照顾人，也惯于替别人决定。他与 P2 曾共同带队，因他擅改撤离安排、使 P2 错失寻找失散者的机会而分开。重逢后他想核实学校的接应能力，再允许公开路线。他必须面对自己的控制欲，让 P2 真正改变计划，复合与原谅由玩家决定。
- N3 是与 P3 结伴而来的浪漫骗子，嘴硬、会逗人，想在学校办一场向外广播的夏日校庆。他曾转播真实寻人信号并虚构“这里有夏天”，P3 收到的正是这个版本。抵达后他急着兑现承诺，又害怕坦白使人离开。P3 能拆穿他、改写节目，并决定是否共同完成这场校庆。
- N4 是 P4 无血缘的成年妹妹，两人无收养监护关系。她亲近粘人、会吃醋，也想成为独立的通讯员。她提前联系过 G，来学校为争取工作机会，却向 P4 隐瞒了打算独自出发的计划。她希望 P4 以恋人的身份重新认识自己，同时保留去远方的愿望。P4 可以回应或拒绝爱情，双方仍能改变联系与相处方式。

每名 N 都要有能辨认的日常行为，以及爱情之外想做成的事。缺点应带来实际分歧，秘密公开后也不自动获得谅解。每名玩家须有自己的目标和能力，能够主动影响对应 NPC。

## G 与公共剧情

G 是在学校等待众人的少女，乐观、有主见，也有脾气和局限。她知道自己身患绝症、时日无多，将这一认知藏着。前期通过一起做事建立亲近，病程留下可察觉的迹象，后期揭晓让玩家重新理解既有相处。

G 与四名玩家分别建立有区别的友情，也与四名 N 实际交往。她兼任全场连接者，负责必要的公共主持。本版暂将 v6 中 G 与 P4 的暧昧调整为友情，四条爱情均采用一对一配置。

从人物愿望长出一条有起因、发展与结果的公共事件。可用“学校第一次面向远方的联合广播”作为候选，让 N1 的课程、N2 的接应方案、N3 的校庆和 N4 的联络发生合作与冲突。其他公共事件也可以，但必须说明每个人做了什么、为何参与，以及谁的决定改变了后续。

四名 N 各自主导至少一幕全体能加入的共同经历，活动由其性格、能力和愿望发起。四幕的玩法与关系变化应有区别，主导 NPC 的对应玩家获得专属互动，其他玩家也有具体任务与回应机会。公共主线在玩家不回应爱情时仍能继续，关键资源与信息不以亲密互动交换。

## 人设驱动与 EDD 校准

本提示词暂将 EDD 用作预期情绪体验的设计检查，不假定它具有统一的行业流程。先判断人物此刻想做什么、会采取什么行动，再检查玩家参与后可能获得什么感受。

对每个关键互动，简要核对预期感受、玩家能做的事、NPC 如何回应，以及行为留下的后果。N1 重点检查玩家是否感到自己教会了他；N2 检查决定权是否真的交还；N3 检查玩家是否成为共创者；N4 检查独立行动与主动亲近能否同时成立。

玩家可能热情、沉默、质疑或拒绝。NPC 须能依据同一人设继续回应，允许关系发展分支。预期情绪没有形成时，检查互动与回应是否充分，避免增加自白或强迫玩家感动。

四名 N 与 G 各有一个影响当前选择的秘密。先发生具体互动，再逐步公开信息，让玩家重新理解当时的行为并作出新选择。秘密分散揭晓，避免结尾轮流自白。死亡、分离或继续相处均可作为归宿，承接已有条件与行动，不统一安排牺牲。

## 本轮交付

先交四名恋陪的人设提案，每人写清一句可用于招募的宣传语、玩家的关系入口、日常互动和主动愿望，并交代缺点、秘密及玩家能够改变的事。再简述四个人怎样推动同一个公共事件，附每席一句 EDD 体验检查。

本轮以人设为主，保持简洁，暂不展开完整分幕正文。人设确定后，再沿这些人物的行动扩展故事大纲。
