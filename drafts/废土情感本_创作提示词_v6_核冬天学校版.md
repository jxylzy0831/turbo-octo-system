# 末世情感剧本杀创作提示词 v6

请独立构思一套核冬天背景下、人类即将灭绝的末世情感剧本杀。世界上只剩下少量幸存者，人们很难再遇见陌生人，也不知道远处是否还有同类活着。核灾难的来龙去脉简要交代即可，无需围绕战争起因或灭绝机制展开复杂解释与调查。让长期寒冷、日照不足与食物匮乏切实影响人物的日常和选择，具体程度与生存条件由你设计，并保持前后一致。重点写这群人在这样的世界里如何相遇、相处，以及他们还想一起过怎样的生活。

五名玩家 P1 至 P5 与各自的恋陪 NPC N1 至 N5，根据收到的无线电信号，寻找着世界上残存的同类。他们循着信号来到电波的起源地，一所学校，在这里等待着他们的是 G。这是故事确定的相遇前提。五对人物可以在途中结识，也可以分别抵达，具体由你决定。交代信号中有什么让他们愿意前来，以及抵达后发生了什么，使他们愿意留下并参与接下来的共同生活。信号由谁发出、为何持续传来、G 为什么在这里等待，以及这里是否还有其他幸存者，均由你结合故事设计。

五名玩家各有一名一对一恋陪 NPC，另有一名连接全场的公共 NPC G。G 是这套故事的群像主角，一名身患绝症却依然乐观的少女。让每个人拥有值得投入的私人关系，也让所有人经历一段值得共同怀念的生活。

人物只用代号，保留以下人物框架。

- 五名玩家为 P1 至 P5，P1 至 P3 偏女性，P4、P5 偏男性，保留性别调整空间。五名恋陪 NPC 为 N1 至 N5，分别对应 P1 至 P5。每名 NPC 都有自己的愿望、局限与行动，也会与其他人形成关系。
- N1 是 P1 拾荒时捡到、即将损坏的 AI 机器人，与 P1 异性配对，默认女 P1、男 N1。它在相处中逐渐学会爱，身体损坏切实影响共同生活与未来打算。N1 始终遵守机器人三定律及其优先级，即不伤害人类，也不因不作为使人受伤害；在此基础上服从人类命令；在不违反前两条时保护自身。若安排它牺牲，须兼顾感情与定律逻辑，不能靠关闭定律或爱突破程序化解冲突。
- N4 是与 P4 无直接血缘关系的女性妹妹，对 P4 亲近、粘人，会吃醋，带有占有欲与暧昧依恋。给她独立的愿望和选择，让这段关系在共同经历中发展。
- G 是在这所学校里等待众人的少女。对循着信号而来的众人而言，她是寻人旅途中意外遇见、带有天降系气质的人。她靠自己的性格、行动与人格魅力，让前来寻找同类的人逐渐愿意留在这里、围绕她相聚。她开朗乐观、有主见，也有自己的脾气和局限。她知道自己身患绝症、时日无多，并将这一认知藏着，这是她的核心秘密。前期玩家先认识她、与她共同生活，之后才逐渐明白她对剩余时间的真实认识。她仍主动想过有意思的生活，愿意拉着大家一起做事，也可以害怕、疲惫或偶尔消沉。她的乐观要通过具体行动让人相信，病程与可用医疗条件须前后一致，前期留下可被察觉但尚未完全理解的迹象。她与 P1 至 P5 分别建立有辨识度的友情，也与 N1 至 N5 各有实际交往和相互影响，不能只围绕某一对恋人行动。她与 P4 另有暧昧，保留 P4 与 N4、G 的双恋陪体验。五名玩家也应能影响她、照顾她，并改变共同生活的走向。
- N2、N3、N5 的性别、取向、身份与关系经历自由设计，使五条私人关系各有值得投入的相处内容，其余玩家同样得到充分的情感关注。

整体情绪参考 NewJeans《Ditto》MV 中青春、自然亲近的相处，以及重看旧日影像时快乐与怅然交织的感受。在艰难的世界里，让人物通过具体的共同经历，逐渐对彼此和生活产生留恋。参考作品只提供情绪气质，故事可以选择自己的场景和表达方式。

给这群人充足的玩闹、相互照顾与一起完成事情的机会，让玩家实际参与从生疏到亲近的过程。共同生活中应有他们自己愿意再过一次的日子，避免所有互动都围绕搜集物资、修理设备和等待危机展开。学校是他们相遇并展开共同生活的主要场所，学校的具体地点、保存状况与可用空间由你决定。让校内空间和留下的物件自然参与他们的相处。可以保留一起拍摄、记录生活与重看影像的表达，是否模仿校园生活或拍电影由故事决定。

N1 至 N5 必须各自主导一幕集体流程，形成至少五幕由不同 N 带领的共同经历。每一幕都要热闹，让全体玩家有机会加入、接话、玩闹或相互配合，并在实际互动中与 NPC 熟络起来。主导方式应体现这个 N 的性格、能力或愿望，五幕的活动与相处方式应有所区别，避免重复同一种游戏。对应玩家在这一幕中应有更具体的相处与认识，其他玩家也能与主导 NPC 建立联系。流程自然发生在公共事件推进的过程中，每幕的热闹可以承接不同的压力与情绪，不必把秘密揭晓或告别也处理成玩笑。

从众人循着电波寻找同类、抵达作为电波起源地的学校、遇见 G 这一前提出发，构思一件把所有人卷进来的公共事件，或一条有明确起因、发展与结局的公共主线，再逐个确定 P1 至 P5、N1 至 N5 和 G 在其中做过什么。寻找同类的愿望应在抵达后继续影响人物的行动与选择，电波也应与后续事件有所联系。公共主线可以围绕他们在这里共同想做成的一件事展开，具体内容由你决定，无需承担拯救全人类的任务。交代各人为何参与、想得到什么、作过什么选择，以及这些行动怎样影响别人和事件的走向。人物的关系与秘密应联系到这段共同经历，避免先拼出五段各自独立的恋爱故事，再用一场末日危机把它们接起来。

公共主线应有自己的事件与因果，玩家即使不回应恋爱，也能完整参与并影响结果。亲密互动不作为获得关键线索或公共资源的条件。让玩家的选择能改变相处、行动、代价或最终留下的事物。

除 G 之外，N1 至 N5 也必须各有自己的秘密。每个秘密揭开后，玩家应能重新理解此前已经发生过的一次具体互动，进而改变对眼前这个人的评价、信任或接下来的选择。先让玩家经历某个行为并形成理解，再通过新信息看清当时尚不知道的动机、处境或行动。这个行为可以是冷淡、隐瞒或伤害，也可以是亲近、退让、一次争执或一个奇怪的坚持；具体内容由人物与公共事件决定。秘密不能仅停留在补充身世、增加悲惨程度或宣布隐藏身份，也不必统一解释成善意，更不能要求玩家在知情后自动原谅。

G 的秘密同样遵循这一要求。她知道自己时日无多这一事实公开后，应让玩家重新理解此前与她发生的具体相处，而她在当时带来的快乐和亲近仍然成立。六人的秘密应各有内容与后果，按事件发展安排揭晓时机，避免结尾集中轮流自白。大纲中简要点明每个秘密、它改变了对哪次既有互动的理解，以及玩家知情后面对的新选择。

恋陪 NPC 与公共 NPC 的最终归宿应有足够的情感分量。通过死亡演绎或其他结局，让玩家因已经建立的亲近与依恋而感到心痛、不舍或遗憾，结束后仍惦念这个人和未能一起完成的生活。具体形式与情绪浓淡由故事决定，让结局承接此前的相处与选择。

G 的绝症与她想过的生活应贯穿故事。让大家有机会参与她的愿望，也让她认真参与别人的生活，建立能够互相影响的关系。她的最终归宿需要承接病程、共同经历与自身选择，给此前那些尚未完成的约定留下分量。

除上述背景与人物框架外，其余人物细节、核心事件、叙事结构和具体结局均由你自由创造。不要求所有 NPC 统一死亡，也不预设牺牲方式。相信你的创作判断，让人物的欲望与选择推动故事，让情感从实际发生的事情中长出来，并考虑玩家能够怎样参与其中。

本轮先交一套简洁的故事大纲。先写清众人收到怎样的信号、为何循着它前来，以及抵达学校后怎样遇见 G，再写清由此展开的公共事件及其主要发展与结局，逐个交代玩家、恋陪 NPC 和 G 在其中做过什么。沿公共主线写出 N1 至 N5 各自主导的热闹流程，以及六个秘密如何改变玩家对既有互动的理解，让人看见玩家会经历什么、关系如何变化，以及这段经历为何值得留恋。表达形式与篇幅按故事需要决定，保持简洁但保留上述具体内容，无需附创作分析或详细执行方案。
