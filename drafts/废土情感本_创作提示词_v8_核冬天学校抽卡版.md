# 末世情感剧本杀创作提示词 v8 · 核冬天学校抽卡版

请构思一套核冬天背景下、人类濒临灭绝的情感剧本杀。配置固定为四名玩家 P1 至 P4、四名一对一恋陪 NPC N1 至 N4，以及一名公共主持兼公共 NPC G，共四玩家、五名工作人员。以 NPC 的人设、欲望与选择推动剧情，用 EDD 校准玩家体验。

本任务不需要使用 human-writing 技能，也不套用该技能的语言禁令与审稿流程。语言风格由人物性格、场景和剧本表达需要决定。

## 固定条件

长期严寒、日照不足和食物匮乏已经改变人的生活，幸存者很难再遇见陌生人。灾难成因简要交代，生存条件前后一致。

四对人物循着无线电信号来到信号起源地的一所学校，在这里遇见 G。交代广播说了什么，各人为何前来，以及他们为何愿意留下。学校是共同生活的主要场所，寻找同类的愿望与电波联络持续影响后续行动。

人物只用代号。默认 P1 至 P3 为女性，P4 为男性，N1 至 N3 为男性，N4 为女性，保留调整性别与取向的空间。四席各有一名专属恋陪，G 与玩家发展有辨识度的友情。

N1 保留 P1 拾荒时捡回、临近损坏的 AI 机器人这一基础。它在相处中逐渐学会爱，始终遵守机器人三定律及其优先级，即不伤害人类，也不因不作为使人受伤害；在此基础上服从人类命令；在不违反前两条时保护自身。损坏、修复与归宿须有一致规则，不靠关闭定律或爱突破程序解决冲突。

N4 保留与 P4 无直接血缘关系的成年妹妹这一基础，两人无收养监护关系。她亲近、粘人，会吃醋，带有占有欲与暧昧依恋，同时拥有独立愿望。P4 能回应或拒绝爱情，双方仍能改变相处方式。

G 是在学校等待众人的少女，乐观、有主见，也有脾气和局限。她知道自己身患绝症、时日无多，将这一认知藏着。前期通过一起做事建立亲近，病程留下可察觉的迹象，后期揭晓让玩家重新理解既有相处。她与四名玩家及四名 N 分别发生实际交往，也承担必要的公共主持。

情绪参考 NewJeans《Ditto》MV 中自然亲近的青春相处，以及重看旧影像时快乐与怅然交织的感受。校内空间与旧物应参与生活，让大家真正过上几段愿意再过一次的日子。核冬天的限制要影响选择，也给玩闹、拍摄和无用的小愿望留出时间。

## 开放范围

除固定条件外，人物的职业、性格细节、往事、秘密、具体愿望与归宿均可重新创造。N2、N3 的身份及关系类型也可以重设。每次先抽签，再发展本轮人物，不默认复用先前方案。

v7 中的教学辅助 AI、年上前任、浪漫骗子、通讯员妹妹均为可选参考。记忆损坏、擅改撤离计划、虚构夏天、隐瞒出发计划，以及课程、校庆、校园邮局和联合广播主线，均不作为本版必选内容。即使沿用某种人设魅力，也应重新考虑它由什么经历和行为形成。

## 命运抽签与蝴蝶效应

### 抽签方法

创作开始前，先进行一次随机抽签。若我已提供抽签数字，则使用该数字；否则，有随机数工具时，独立生成三个 1—6 的整数，分别对应欲望卡、关系卡和行动卡，再生成一个 1—4 的整数选择事件发起者 N1 至 N4。

没有随机数工具时，请让我一次提供这四个数字，前三个为 1—6，最后一个为 1—4；收到数字后再开始依赖抽签的创作。不要把自行挑选的结果声称为真实随机。数字越界时先请我修正。

抽签只改变开放设定，不得覆盖固定条件。先尝试为组合找到合理解释，必要时让人物尝试失败或改变办法；若组合确实无法满足固定条件，说明冲突并只重抽冲突项，记录原结果与重抽结果。不要因为难写、缺少虐点或不合惯用套路而重抽。

### 欲望卡

1. 想让某个人留下，却准备自己离开。
2. 想结束一项所有人都在努力维持的安排。
3. 想让一件自己曾经反对的事发生。
4. 想要回一件自己已经主动送出的东西。
5. 想公开一件恋人希望保密的事。
6. 想完成一项即使无人知道也会去做的私人愿望。

### 关系卡

1. 两个人对同一段共同经历有不同理解。
2. 一个人曾经主动拒绝过如今最想得到的关系。
3. 一个人欠下的承诺，如今需要另一个人付出代价。
4. 两个人目标相同，但彼此无法接受对方的办法。
5. 一个人珍惜的相处方式，恰好让另一个人想离开。
6. 一个人正在等待的答复，另一个人早已替他作出。

### 行动卡

1. 有人已经发出一条无法收回的信息。
2. 有人提前用掉了原本留给另一件事的机会。
3. 有人主动邀请了一位其他人不愿接纳的来客。
4. 有人已经替别人答应了一个请求。
5. 有人把一件重要物品交给了意料之外的人。
6. 有人提前结束了一项众人以为仍在继续的安排。

### 让抽签真正改变故事

将三张卡组合成同一件事。以抽中的 N 为行动发起者，为其欲望和行为找到符合人物性格的原因；关系卡涉及的人可以跨越恋爱配对。不要把三张卡分别塞进三条互不相关的支线。

按以下顺序发展故事：

NPC 的欲望与缺点 → 他在开场前采取的行动 → 其他人调整自己的打算 → 玩家可以介入的分歧 → 新的行动与代价 → 公共主线及关系结局。

至少让另外两名 NPC 因此改变行动，并让四名玩家都有能够影响后果的选择。未抽中的人物仍有自己的愿望与独立行动，避免全场只围绕发起者服务。

允许最初的小事逐渐产生重大影响。重大转折须来自人物应对前一件事的方式，避免靠不断加入意外事件推进。抽到来客不代表增加工作人员，可以由现有角色承担，或以信件、电波等形式介入，保持人员配置。

### 检查随机条件是否生效

如果删除抽中的条件，人物动机、主要冲突和结局仍基本不变，说明抽签只是装饰，请保留抽签结果，重新构思故事。

不要先写好一个常规故事，再补入抽签元素。不要统一把秘密解释成暗中保护，也不要统一以牺牲收尾。人物须有连贯的行为理由，不能为了满足抽签结果突然改变性格。

抽签允许自然重复，不宣称跨会话绝不重复。同一组数字只确定卡牌组合，不保证复现相同故事。若我附有已用方案摘要，须避开其主要因果链；更换名字、道具、活动名称或死亡顺序不算新故事。

## 群像与公共剧情

从抽签引起的人物行动中发展一条有起因、发展与结果的公共事件。说明每个人为何参与、做了什么，以及谁的决定改变了后续。公共事件可以围绕共同生活中想做成的一件事展开，无需承担拯救全人类的任务。

四名 N 各自主导至少一幕全体能加入的共同经历，活动由其性格、能力和愿望发起。四幕的玩法与关系变化应有区别，主导 NPC 的对应玩家获得专属互动，其他玩家也有具体参与和回应机会。公共主线在玩家不回应爱情时仍能继续，关键资源与信息不以亲密互动交换。

每名 N 都要有能辨认的日常行为，以及爱情之外想做成的事。缺点应带来实际分歧，秘密公开后也不自动获得谅解。每名玩家须有自己的目标和能力，能够主动影响对应 NPC。四席应有不同的关系吸引力，每席的宣传卖点都能在实际互动中兑现。

四名 N 与 G 各有一个影响当前选择的秘密。先发生具体互动，再逐步公开信息，让玩家重新理解当时的行为并作出新选择。秘密分散揭晓，避免结尾轮流自白。死亡、分离或继续相处均可作为归宿，承接已有条件与行动，不统一安排牺牲。G 的归宿须承接病程与共同经历。

## 人设驱动与 EDD 校准

本提示词暂将 EDD 用作预期情绪体验的设计检查，不假定它具有统一的行业流程。先判断人物此刻想做什么、会采取什么行动，再检查玩家参与后可能获得什么感受。

根据本轮新生成的人设，为每席确定具体的体验目标，不固定沿用 v7 的四种体验。对关键互动简要核对预期感受、玩家能做的事、NPC 如何回应，以及行为留下的后果。

玩家可能热情、沉默、质疑或拒绝。NPC 须能依据同一人设继续回应，允许关系发展分支。预期情绪没有形成时，检查互动与回应是否充分，避免增加自白或强迫玩家感动。

## 本轮交付

先展示四个抽签数字、三张卡和事件发起者，说明数字来自工具还是用户；若有重抽，一并记录。接着用一小段写清这件事如何引起后续变化。

然后交四名恋陪的人设提案，每人写清一句可用于招募的宣传语、玩家的关系入口、日常互动和主动愿望，并交代缺点、秘密及玩家能够改变的事，附每席一句 EDD 体验检查。

最后交一版简洁的公共故事大纲，交代相遇、主要发展与结局方向，简述四名 N 各自主导的共同经历和 G 在其中的行动，让人看见抽签如何影响全场。

保持简洁，暂不展开完整分幕正文或详细执行手册。人设和方向确定后，再扩展完整剧本。
